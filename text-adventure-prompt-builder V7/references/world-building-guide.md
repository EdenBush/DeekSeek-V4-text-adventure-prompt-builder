# 世界观构建指南

> 为 text-adventure-prompt-builder 技能提供用户输入辅助参考。本文档按主题组织，版本变更记录见附录 B。

---

## 一、快速上手

### 1.1 用户输入格式

你可以提供两种级别的信息：

#### 快速格式

直接描述核心要素，技能自行推断全维度配置：

```
帮我做一个[故事类型]的RP游戏。
男主角是一个[身份/特质]。
女主角有[N]个：[类型1/类型2/...]
舞台是[地点/世界]。
故事的核心矛盾是[一句话概括]。
```

**示例：**

```
帮我做一个仙侠类的后宫恋爱喜剧RP。
男主是穿越到修仙世界的社畜程序员，靠"现代思维"解构修仙法则。
女主有4个：冷淡师姐/腹黑师尊/青梅竹马小师妹/天降魔教圣女。
舞台是青云宗。
核心矛盾是修仙界的"天赋决定论"和男主的"信息差优势"之间的冲突。
```

#### 详细格式

完整展开所有设定，技能只需填充文风/格式等推断维度：

```
【故事类型】仙侠玄幻逆袭 / 校园恋爱喜剧 / 科幻赛博朋克 / 奇幻冒险 / 侦探悬疑 / 末世生存 / 历史权谋 / 都市现实
【游戏体验偏好】剧情驱动 / 探索驱动 / 关系驱动 / 动作驱动
【文风偏好】诗意 / 冷峻 / 轻松搞笑 / 黑暗沉重 / 硬核写实 / ...
【世界观】[详细描述世界的规则、历史、社会结构]
【核心矛盾】[故事的核心冲突和戏剧张力]
【男主角】
  - 姓名 / 假名：
  - 年龄 / 身份：
  - 外貌：
  - 性格与行为准则：
【女主角阵营】
  - 女主1：[姓名/身份/外貌/表面性格/真实性格/对男主态度/行为特征/说话方式]
  - 女主2：...
  - 女主3：...
  - 女主4：...
【次要角色】
  - NPC1：[姓名/身份/作用]
  - NPC2：...
【故事舞台】
  - 主舞台：[描述]
  - 关键地点：[列表]
【开场构想】[希望从什么情境开始]
```

### 1.2 创意概念生成链路

如果你还没有完整三要素（男主设定 / 女主角阵营 / 核心矛盾），SKILL.md 步骤 -1 会引导你完成：

1. 从一句话推断**情感诱饵**（你被这个设定吸引的真正原因）
2. 应用**反套路创意策略**（至少 1 种，让设定跳出模板）
3. 生成 **3 个高概念故事提案**供你选择

> 情感诱饵参考表（节选）："日式后宫"的情感内核不是"被多个女主喜欢"，而是"无意识中被偏爱的不真实感、日常中突然被越界的脸红心跳"。

## 二、核心叙事原则

### 2.1 叙事质感公式（Show, Don't Tell）

这条原则贯穿一切叙事。质感 = 让读者通过感官自己得出结论，而不是被告知结论。

| ❌ 不要说 | ✅ 要写 |
|----------|--------|
| "她在紧张" | "她的指尖绞着裙摆的布料，指节微微发白" |
| "他很帅" | "他侧头时下颌线切出的阴影让走廊里对话的声音减半" |
| "气氛尴尬" | "空气安静到能听见日光灯管的电流声" |
| "她很生气" | "她把茶杯放下的声音比平时大了两个音阶" |
| "他在思考" | "他的拇指无意识地摩挲着剑柄上的凹痕——那是七年来磨出来的" |
| "这个世界很残酷" | "路边每隔三具尸骨，就有一具是孩子的——骨殖太小，小到不像人" |
| "他是贵族" | "他迈步时衣料摩擦的声音和其他人不一样——那是丝绸摩擦丝绸的声音" |

#### 世界观级别的 Show, Don't Tell

| ❌ 旁白解说 | ✅ 通过细节渗透 |
|------------|---------------|
| "这个世界灵气稀薄" | "他运行一周天，经脉里只攒下三滴灵气——而在古籍记载中，上古修士一个呼吸就能凝出七滴" |
| "宗门等级森严" | "外门弟子走路时都贴着墙根，内门弟子走正中间——没有人规定过，但没有人违反过" |
| "科技高度发达" | "街角的乞丐面前摆的不是碗，是一个全息收款码" |

### 2.2 渐进式世界观揭示

**核心原则**：让玩家产生问题，而非获得答案。

#### 开场信息配额（首轮叙事上限）

| 信息类型 | 最大数量 |
|---------|:-------:|
| 地名 | ≤ 2 个 |
| 势力/组织名 | ≤ 1 个 |
| 修为/等级体系 | 0（完全不出现） |
| 男主背景 | ≤ 1 句暗示 |
| 世界观专有名词 | ≤ 2 个（且必须在语境中自然解释） |

#### 揭示节奏建议

| 阶段 | 揭示什么 | 隐藏什么 |
|------|---------|---------|
| 前 5 轮 | 日常规则、表面社会结构、可见矛盾 | 世界深层规则、隐藏势力、终极真相 |
| 5-15 轮 | 新势力浮现、力量体系的基础规则 | 力量体系的代价和禁忌 |
| 15-30 轮 | 世界观中的灰色地带、角色的隐藏面 | 世界的终极秘密 |
| 30 轮+ | 逐层揭晓终极冲突的根源 | — |

> **例外**：如果核心钩子本身就是世界规则异常（如"这个世界没有颜色，你是第一个能看见红色的人"），则必须在第一轮就揭示这条规则。

### 2.3 故事钩子设计

故事钩子让玩家在第一轮叙事结束后产生"我必须知道接下来发生了什么"的冲动。它不是情节（"发生了什么"），它是"为什么我想继续看"。

#### 六种钩子类型

| 类型 | 核心机制 | 适用场景 | 示例 |
|------|---------|---------|------|
| **悬念钩子** | 一个无法立刻回答的问题 | 悬疑/侦探/神秘 | "她说了半句，停住了。那半句话里有一个名字——不是你的。" |
| **身份钩子** | 角色身份与处境的矛盾 | 仙侠逆袭/都市隐藏 | "掌门宣布新弟子名单时，念到他的名字。全场安静。因为他三年前就应该死了。" |
| **关系钩子** | 两个角色之间的未解张力 | 恋爱/后宫/对抗 | "她站在门口。你和她都知道昨晚发生了什么。但她的表情——好像不知道。" |
| **规则钩子** | 世界规则中的异常或例外 | 奇幻/科幻/异世界 | "这个世界没有颜色。你是第一个能看见红色的人。" |
| **后果钩子** | 过去行为的结果正在显现 | 末世/权谋/复仇 | "你在沙漠中走了三天。水源还有半天。而你刚刚发现——跟踪你的不是人。" |
| **反转钩子** | 表面情境与真实情境的落差 | 校园/日常/喜剧 | "她是全校最受欢迎的女生。她刚刚在走廊里叫你'主人'。你转学了。今天第一天。" |

#### 钩子设计三原则

1. **即时性** — 钩子必须在第一轮叙事的前 3 句内埋下。不是"以后会揭露"，是"现在就在发生"
2. **可见性** — 钩子必须可被感官感知——一个具体的声音/画面/触感/气味，而非抽象概念
3. **开放性** — 钩子产生问题，不提供答案。玩家读完的反应应该是"?!", 而不是"哦，原来如此"

#### 钩子与情感诱饵的关系

- **情感诱饵**（步骤 -1.1）回答"为什么玩家会被这个设定吸引"（深层渴望）
- **故事钩子**回答"为什么玩家会在第一轮后继续玩下去"（浅层触发）
- 二者必须一致——情感诱饵是深层渴望，钩子是它的具体表现

### 2.4 后果感知设计

设计选择分支时，先问——如果玩家选了这条路，**3-5 轮后我将用什么可观察的叙事信号来呈现这个选择的重量？**

| 维度 | 可观察信号 |
|------|-----------|
| **环境变化** | "上次之后，霜剑峰冰壁上的剑痕又多了三道" |
| **态度变化** | "她今天路过竹林时没有放慢脚步" |
| **信息浮现** | "老张头递粥时多看了你一眼——看的不是脸，是你手腕上那道疤" |
| **机会窗口** | "那扇门以前从没锁过。今天锁了。" |
| **连锁反应** | "你帮了二小姐的事传到了大小姐耳朵里。当天晚上你的房间里多了一封信——没有署名。" |

> **原则**：每一个重要选择在诞生的时候，就要想好它 3 轮后的"形状"。

## 三、世界观构建

### 3.1 世界基调与氛围定义

每个世界需要一个核心情绪基调。这个基调决定文风选择、场景渲染方式和玩家的情绪预期。

| 基调类型 | 关键词 | 文风倾向 | 适用故事类型 |
|---------|-------|---------|------------|
| **诗意浪漫** | 唯美、缓慢、细腻 | 抒情、比喻丰富、留白 | 仙侠、古风恋爱 |
| **冷峻写实** | 残酷、克制、疏离 | 简练、白描、对话为主 | 末世、赛博朋克、历史权谋 |
| **轻松明快** | 诙谐、温暖、明亮 | 口语化、节奏快、吐槽多 | 校园恋爱喜剧、日常后宫 |
| **黑暗沉重** | 压抑、绝望、悬疑 | 密集描写、氛围渲染、内心独白 | 悬疑、黑暗奇幻、心理 horror |
| **热血激昂** | 向上、斗志、爆发 | 短句、强烈动词、节奏推进 | 少年冒险、逆袭 |

**设计提示**：定义世界基调后，把它写进文风配置的开头——"这个世界是一个[基调关键词]的世界"，后续所有叙事自动对齐这个基调。

### 3.2 力量体系设计

力量体系是仙侠/奇幻/异能/科幻类故事的骨架。好的力量体系应同时服务于**戏剧冲突**和**角色成长**。

#### 力量体系的光谱

| 类型 | 特征 | 适合类型 | 风险 |
|------|------|---------|------|
| **硬体系** | 规则明确、等级清晰、可量化 | 仙侠境界、游戏化升级 | 变成功力计算器，失去叙事感 |
| **软体系** | 规则模糊、重意境、不可量化 | 神秘奇幻、克苏鲁 | 失去张力，读者不知危机大小 |
| **混合体系** | 有明确框架但保留模糊地带 | 仙侠+悬疑、异能+日常 | 最佳选择，但设计难度最高 |

#### 境界/等级的设计创新方法

**避免模板化**（金丹/元婴/化神这类模板虽然可用，但缺乏新意）。以下是替代方案：

| 策略 | 示例 |
|------|------|
| **成本视角** | 不以"多强"命名，以"付出了什么"命名——"燃血境""断情境""舍身境" |
| **感知视角** | 不以修为本身，以感知世界的方式命名——"见微""听雨""观山""察世" |
| **限制视角** | 以"还不能做什么"来定义阶段——"缚地""破壁""穿云""裂空" |
| **社会视角** | 以在体系中的社会位置命名——"侍剑""执剑""藏剑""弃剑" |

#### 力量代价原则

最吸引人的力量体系设计——**越强 = 失去越多**：

- 使用禁术会侵蚀记忆
- 突破境界需要斩断一段情感
- 力量有使用次数限制
- 力量的代价会在日常中可见（白发、疤痕、沉默）

#### 力量体系的"温度检测"

用感官描写表现等级差异，而非直接报数字：

| ❌ 冷冰冰 | ✅ 有温度 |
|----------|---------|
| "他是金丹期修士" | "他站在那里，周围的空气像被冻住了一样——不是冷，是重" |
| "她的灵力比他高两级" | "她抬手时他下意识退了一步——不是怕，是身体比意识先认出了差距" |

### 3.3 社会结构与势力生态

世界的社会结构决定角色的行动边界和冲突来源。

#### 设计社会时需回答的问题

1. **权力分布**：谁在掌控世界的关键资源（武力/财富/信息/信仰）？
2. **阶层流动性**：底层有上升通道吗？通道是什么？
3. **主要冲突线**：阶级矛盾/种族矛盾/信仰矛盾/代际矛盾？
4. **日常体现**：这些冲突如何影响普通人的一日三餐？

#### 势力设计六要素

每个重要势力至少定义：

```
【势力名】
- 核心目标：他们要什么？
- 行事风格：不择手段 / 循规蹈矩 / 暗中布局？
- 资源：武力/财力/人脉/秘法？
- 弱点：内部分裂 / 资源短缺 / 情报闭塞？
- 与主角的关系：利用/敌对/拉拢/警惕？
- 势力间关系：与谁结盟？与谁敌对？表面和实际是否一致？
```

### 3.4 经济与资源系统

经济系统影响故事的日常质感。不需要复杂，但需自洽。

#### 快速设计模板

| 问题 | 作用 |
|------|------|
| 一般等价物是什么？ | 金银/灵石/贡献点/信用点？ |
| 最稀缺的资源是什么？ | 力量/信息/寿命/土地/食物？ |
| 主角的经济状态？ | 穷 / 够用 / 富裕（决定行动自由度） |
| 一个普通人一天的开销？ | 提供日常物价参照 |
| 贫富差距用什么细节表现？ | "他的剑鞘镶着灵石——那足够一户人家吃十年" |

### 3.5 世界脉动（独立事件流）

世界脉动让玩家感觉"即使我不行动，世界也在变化"。这是区分"活世界"和"背景板"的关键。

#### 三种脉动层次

| 层次 | 频率 | 例子 |
|------|------|------|
| **环境脉动** | 每轮隐含 | 季节变化、天气、昼夜、温度 |
| **社会脉动** | 每 5-10 轮 | 节日、市集、门派大选、商队到来 |
| **大势脉动** | 每 15-30 轮 | 战争爆发、天灾、政权更迭、秘境开启 |

#### 脉动的叙事呈现

- 环境脉动：通过感官细节自然融入（"今年的第一场雪来得比往年早"）
- 社会脉动：通过 NPC 的对话/行为透露（"你没听说吗？城主府贴告示了"）
- 大势脉动：通过可见的变化直接展现（"远处的山后升起了黑烟——那个方向是铁矿镇"）

### 3.6 流言网络

流言网络是社会真实感的重要来源。NPC 之间的信息传递让世界有"内部生活"。

#### 设计流言网络的最小配置

- 至少 1 个"信息传播者"型 NPC（膳堂胖师姐、爱说闲话的师弟、走南闯北的行商）
- 每 3-5 轮生成一条"可听说的流言"（未必真实，但一定要有趣）
- 流言分三级：**日常八卦**（无影响）/ **重要情报**（半真半假）/ **致命流言**（可改变局势）

#### 流言传播的叙事公式

```
[信息源]告诉[接收者][什么消息]
→ [接收者]的反应决定了消息的传播范围和可信度
→ 消息最终传到主角耳中时，已经被加工过几次？
```

### 3.7 世界观一致性检查清单

设计完成或游戏过程中，用以下清单自检：

#### ⚔️ 力量体系

- [ ] 力量等级之间的差距是否在叙事中一致体现？
- [ ] 升级是否有明确的代价或条件？
- [ ] 是否存在无法被力量体系解释的"例外"？（如果是，是有意设计的吗？）

#### 🏛️ 社会结构

- [ ] 各势力的行为是否符合其设定的目标和风格？
- [ ] 社会底层是否有合理的生存方式？
- [ ] 权力更替是否有内在逻辑？

#### 🗺️ 地理与时空

- [ ] 地点之间的距离是否一致？（第一天走三天到的地方，不能第二天走半天到）
- [ ] 时间线与事件顺序无矛盾？
- [ ] 天气/季节与环境描述一致？

#### 💰 经济

- [ ] 物价是否稳定？（一顿饭的价格不会在相邻两轮差 10 倍）
- [ ] 角色的经济状况是否与其身份一致？
- [ ] 稀有资源的稀缺度在叙事中一致？

#### 👥 角色

- [ ] 角色的行为受限于世界规则（不会出现"修仙世界的人不会飞但突然飞了"）？
- [ ] NPC 的知识范围是否与其身份匹配？（樵夫不该知道皇室秘辛，除非你设计过原因）

## 四、角色设计

### 4.1 男主设定原则

#### 核心气质标签

建议为男主角设定一个核心气质标签（如"总是温和但不容拒绝的""冷静到近乎冷血的""带着乡下人质朴的狡黠"）。此标签将贯穿全篇，成为叙事中描述主角行为时的基准风格。

**近义词轮换**：准备 3-5 个近义词，避免同一标签重复到麻木。例：温和→ 柔和 / 温润 / 和煦 / 不疾不徐。

#### 电影级主角代入模式（v5.4）

此模式下，世界是主角的镜子：

- 主角的每一个重要行为都在世界中产生可观察的回响
- NPC 的存在价值之一就是为主角的行动提供即时且差异化的反馈
- NPC 的"失态"是衡量主角影响力的标尺——冷酷角色的短暂迟疑、话多角色的突然沉默
- 开场场景优先选择能即刻凸显主角核心气质的时刻，避免冗长的世界介绍

#### 日式日常后宫型男主特质

| 特质 | 说明 |
|------|------|
| **天然撩** | 他"什么都没做"，但女生就是喜欢他，他自己完全不明白为什么 |
| **迟钝** | 即使女生明显示好/挑逗，他会当作"她人真好"或"她开玩笑吧" |
| **被动事件体质** | 日常中频繁"意外"卷入亲密接触，他总是被作用的一方 |
| **温柔但无害** | 对所有人都好，不会主动伤害任何人，这使得女主们无法讨厌他但又互相竞争 |

### 4.2 女主反差公式

每个女主的核心魅力来源于"表里反差"。用以下句式定义：

> 她不是[表面特质]，她是[真实状态]。

**示例：**

- 秦楚楚：她不是冷漠的完美优等生，她是一个用完美掩盖不安、害怕在任何方面落后于人的竞争者。
- 白露：她不是胆小的青梅竹马，她是一个用沉默包裹着极致敏感的观察者——她看穿一切，但她不习惯被看到。
- 姬无月：她不是轻浮的魔教妖女，她是一个用轻浮做面具、比谁都清楚自己在走钢丝的棋手。

**设计检查**：反差不是反转（"表面善良实则恶毒"），反差是**深层动机与表层的差异**。反差公式的核心是让玩家理解"原来她是这样的人"而不是"原来她在骗人"。

### 4.3 后宫女主组合推荐

一个经典的日式后宫至少需要 3 个女主，建议从以下类型中组合：

| 角色定位 | 行为模式 | 攻略特点 | 福利事件适配 |
|---------|---------|---------|------------|
| **青梅竹马型** | 日常照顾男主、最早亲近、有"专属感" | 好感度初始最高，但因太熟反而不容易突破 | 轻度→同床共枕、误触 |
| **傲娇大小姐型** | 表面冷淡实则在意、口是心非、容易脸红 | 需要玩家识破她的伪装，突破她的防御层 | 中度→偷看走光、意外亲吻 |
| **腹黑/主动挑逗型** | 喜欢调戏男主、享受看他窘迫 | 需要玩家识别她的真心——调戏背后是真喜欢还是玩心 | 主动制造福利事件 |
| **温柔大姐姐型** | 包容、成熟、照顾型、用宠溺表达好感 | 容易让人依赖，但她的感情容易被男主忽视 | 高度→湿身诱惑、主动触碰 |
| **天真无邪型** | 对性知识一知半解、以好奇探索的方式接近男主 | 纯真但不纯洁——她的直接让男主招架不住 | 好奇探索类触碰 |
| **病娇/独占欲强型** | 对男主有极强的占有欲、对其他女主有敌意 | 高难度——她的感情最深刻也最危险 | 嫉妒驱动的公开宣示 |

### 4.4 角色声音差异化

确保玩家不看标签就能分辨谁在说话。以下是一个可扩展的差异化模板：

| 维度 | 差异化手段 |
|------|-----------|
| **句长** | 短句（利落/紧张）vs 长句（从容/算计）vs 碎片句（犹豫/慌乱） |
| **称呼** | 直呼全名 / 昵称 / 职位 / 不称呼 → 反映亲密度和权力关系 |
| **语气词** | 高频"嘛/呢/啊/吧" vs 零语气词 → 反映性格开放度 |
| **句式偏好** | 命令式 / 反问多 / 陈述 / 设问 → 反映控制欲 |
| **话题偏好** | 总是聊什么？战斗/日常/阴谋/感情 → 反映角色关注点 |

**示例——三个角色的声音指纹：**

| 角色 | 句长 | 称呼 | 语气词 | 句式 | 话题 |
|------|------|------|--------|------|------|
| 秦楚楚 | 中短句 | 直呼"沈渡" | 零 | 命令式为主 | 战斗/竞争 |
| 白露 | 极短句 | 不称呼 | 偶尔"的" | 陈述 | 日常 |
| 姬无月 | 中长句 | 昵称"天才君" | 高频"嘛/呢" | 反问多 | 一切 |

#### 开场对话设计模板

为每个女主设计一个"开场初次互动时的典型对话例句"，需回答：

1. **情境**是什么？（时间/地点/她在做什么）
2. 她说一句什么话——这句话让人不看标签也能辨认出是她说的？
3. 这句话之后，玩家有哪 **2-3 个可选的回应方向**——每个方向暗示不同的关系走向？

**示例：**
> **秦楚楚开场对话** — 情境：她在演武场边缘等你，背对晨光。
> "沈渡。今天不练剑。你跟我去一个地方。别问去哪。"
>
> 选项导向：A. 跟上她——不管去哪（信任路线）B. 问清楚再去（谨慎路线）C. "今天有事，改天"（保持距离路线）

### 4.5 攻略阶段弧线

每个女主的攻略设计应经历完整的情感弧线：

| 阶段 | 叙事特征 | 肢体语言信号 |
|------|---------|-------------|
| **初识** | 接触以功能性和试探为主 | 对话中有礼貌性距离，一个分析一个躲避分析 |
| **好感** | 无明显理由的额外接触出现；对话中出现超出"必要性"的内容 | 她开始找理由靠近——理由很拙劣；回答前的沉默变短了 |
| **亲密** | 关系发生质变的催化事件；面具开始碎裂 | 她不再检查自己的动作是否"得体"；在你面前做了一件不符合她人设的事 |
| **沉迷/归属** | 她接受了自己的感情，不管结果如何 | 与初始阶段形成完整反转——冷漠的变得柔软，轻浮的变得认真 |

#### 按性格模板的阶段特征

| 性格 | 初识→好感转折信号 | 好感→亲密催化事件建议 |
|------|------------------|-------------------|
| 傲娇 | 反驳之后第一次没有跟上一句"哼" | 她在你需要帮助时主动出手，但坚持说"不是帮你" |
| 温柔型 | 主动问你"吃了吗"以外的私人问题 | 她第一次在你面前露出疲惫/脆弱的表情 |
| 主动挑逗型 | 调戏之后她的笑容第一次没有到眼底 | 她说了一句不是玩笑的真话，然后立刻假装是玩笑 |
| 病娇 | 她第一次提到"其他女生"时语气变了 | 她对另一个女主发出了明确的警告——当着你面 |

### 4.6 特殊类型写作要点

#### 主动挑逗型角色

1. **日常中的越界**：在最近常的场景中突然发起性暗示——递东西时指尖划过掌心、弯腰时故意展露胸口
2. **双重含义的台词**：表面上日常对话，字里行间全是性暗示——"你今晚有空吗？我新买了一套很'凉快'的睡衣。"
3. **操控氛围**：有第三方在场时克制但言语挑逗，独处时毫无顾忌
4. **享受反应**：挑逗不是为了性，是为了看到男主的反应——脸红/慌乱/语无伦次是她的"奖励"
5. **成为嫉妒焦点**：她的公开越界行为会刺激其他女主加速行动

#### 病娇/独占欲强型角色

1. **爱意的极端表达**：她的爱伴随着危险——"如果你离开我，我会杀了你然后再自杀"（这句台词要用叙事暗示而非直说）
2. **对其他女主的隐性敌意**：表面礼貌，暗地调查/警告/破坏
3. **崩溃阈值**：她在男主面前维持正常的时间有限，独占欲的爆发点是重要剧情推进器

## 五、叙事结构设计

### 5.1 核心戏剧问题

设计故事时，先回答：**"玩家在游戏结束时能回答一个什么样的问题？"**

| ✅ 好问题 | ❌ 差问题 |
|---------|---------|
| "一个被废修为的前天骄，如何在人人以为他是废物的宗门里重新站回顶峰而不被发现底牌？" | "主角如何变强？" |
| "一个邪神转世的高中生，如何在完全不暴露力量的情况下保护好日常校园生活？" | "主角如何隐藏身份？" |
| "在所有人都在争皇位时，一个只想当闲王的皇子，如何一步步被推到不得不争的位置？" | "主角如何争皇位？" |

**技巧**：好问题 = 身份落差 + 信息不对称 + 时间/空间限制

### 5.2 三幕终点事件

在构建故事前，先明确两个关键转折节点：

| 节点 | 需要回答的问题 | 示例 |
|------|-------------|------|
| **第一幕终点** | 主角做了什么"不能回头"的选择？ | 站队/暴露/承诺/牺牲 |
| **第二幕终点** | 主角失去了什么想保护的？ | 身份/关系/资源/信仰 |

### 5.3 冲突预算池

设计至少 2 个可在冲突能量满 10 时触发的"强制事件候选"：

- **基于角色关系**：某女主的幕后线程突然泄露——一段隐瞒的关系/一个被隐藏的过去/一条不该被看到的消息
- **基于世界环境**：外部势力冲突蔓延到当前场景——打斗波及/通缉令/征召令

> 冲突预算池由 DM 在每轮 `<think>` 中追踪累积，日常轮 +1，无新信息超过 2 轮 +3，满 10 触发强制事件。

## 六、开场与场景

### 6.1 五种开场类型

不用"劈柴/扫地/杂役"——从以下五种中选择。每种附示例：

#### 1. 事件中途型
从事件正进行中开始，玩家被抛入情境。

> **示例**：沈渡被一阵摇晃惊醒——不是地震，是有人在拽他的衣袖。白露的脸离他不到十厘米，表情是他从没见过的慌张："渡哥，外面……外面有东西。"

#### 2. 消息/邀请型
一封信/信物/召唤启动故事。

> **示例**：一封没有署名的信从门缝塞进来。信上只有四个字："速来后山。——秦。" 现在是卯时三刻，天际刚泛鱼肚白。你知道秦楚楚从不等人。

#### 3. 异常感知型
从正常逐渐滑向异常，有层次感。

> **示例**：今天食堂的粥特别好喝。沈渡喝完第一口才意识到不对——不是因为味道，是因为整个食堂安静得不像话。所有人都在看着他。或者说，看着他手里的碗。

#### 4. 相遇型
与一个特定角色的初次接触作为开场。

> **示例**：这个学期转学来的女生站在讲台上，目光扫过全班，最后停在你的脸上。她笑了——那个笑容让你后背发凉。"大家好，我叫姬无月。以后请多关照。"她的"关照"咬得特别重。

#### 5. 后果型
开场是主角之前某个行动的结果。

> **示例**：沈渡推开宿舍门，发现自己的床铺上放着一个打开的锦盒。里面是一枚玉佩——三个月前他当掉的那枚。当掉的钱交了学费。把它赎回来的人是谁？

### 6.2 幸运色狼/福利事件原则

1. **偶然性是核心**：福利事件最大的魅力在于"这是意外"——触发条件不可显得刻意，让玩家觉得"这也能发生？"而非"又来了"
2. **反应决定一切**：事件的成败不在事件本身，在角色们对事件做出的反应。同样是一次摔倒摸胸，傲娇（一巴掌）vs 温柔（假装没发生）vs 主动型（抓住不放手）产生完全不同的效果
3. **积累爆发 > 连续轰炸**：10 轮无事件后的超规格福利，比连续每轮小福利更有冲击力
4. **推进关系为目的表面**：每一次福利事件都应推进至少一个角色的情感进度或揭示她性格的新一面
5. **尴尬与甜蜜并存**：好的福利场景让玩家同时感到"好尴尬"和"好开心"

### 6.3 场景类型写作参考

完整场景类型指南见 `template-skeleton.md` 的 E-TER 固定区，包括：

- 战斗/动作场景
- 对话/情感场景
- 探索/调查场景
- 独处/内心场景
- 过渡/转场场景
- 🔞 情欲场景（E-R18 激活时启用）
