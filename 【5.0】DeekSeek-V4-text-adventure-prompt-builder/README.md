## 📖 这是什么？

**Text Adventure Prompt Builder** 是一个专为大型语言模型设计的**元提示词（Meta-Prompt）技能**。它不只是生成一份 DM 提示词——它更像一位资深叙事设计师与恋爱喜剧编剧的结合体，在接受你的世界观构想后进行“叙事编译”，交给你一整套可控、可演进、可沉浸的互动故事引擎。

**v5.0 是日式日常后宫的特化版本**。在 v4.0“写什么才精彩”的蓝图引擎基础上，v5.0 回答了后宫类故事最核心的两个问题：**“如何让多线关系自然演进而不失衡”**，以及**“如何让福利场景成为叙事推进器而非廉价杀必死”**。

## 🆕 v5.0 新特性

### 💘 后宫关系管理系统 (E-HAREM)
后宫不是“所有人都自动喜欢你”——每个女主的感情都有独立的分量。新增**三维追踪**（宠爱值/嫉妒值/亲密进度），后宫事件触发引擎让修罗场、暗中较劲、意外同盟、集体危机自然涌现。DM 在每轮叙事中自动维护多女主关系平衡。

### 🍀 幸运色狼/福利事件系统 (E-ECCHI)
谁说尴尬的身体接触不能推进剧情？**七大经典福利类型**（误触摔倒/意外目击/同床共枕/更衣撞见/湿身诱惑/借位亲吻/敏感触碰）附带独立计数器，能量累积自动触发。每一次脸红心跳的意外都是关系进展的加速器——而不仅仅是服务读者的片段。

### 🎭 六维主动类型角色标签
女主不再只是“傲娇”或“温柔”。v5.0 引入**六大主动倾向分类**：被动害羞型 / 半推半就型 / 主动挑逗型 / 痴女肉食型 / 反差闷骚型 / 好奇探索型。每种类型有独立的行为模式、挑逗风格和亲密场景触发逻辑——让每个女主的越界方式都独一无二。

### 💬 日常挑逗场景类型 (类型七)
在日常对话中突然越界——前一秒还在讨论晚饭吃什么，下一秒她的手就放在了不该放的地方。新增**三种风险等级系统**（安全/有风险/高风险），让公开场合的隐晦挑逗和私密空间的肆无忌惮产生完全不同的叙事张力。

### 🔞 NSFW 增强 v5.0 升级
性癖标签系统从“可选描述”升级为**可演进的叙事线索**。特殊癖好不再是背景设定——它们成为角色弧线的一部分，在亲密进度推进中逐步解锁、被发现、被回应。

## ✨ 核心特性

### 🧠 全维度智能推断
- **四维推断引擎**：自动从用户描述中推断 `故事类型 × 文风配置 × 游戏体验 × 开场模式`
- **六维文风调色板** + **第七维情色描写**：叙事节奏 / 描写密度 / 抒情程度 / 幽默模式 / 成人描写 / 对话风格 / 情色程度
- **九种故事类型**原生支持（🆕 新增日式日常恋爱后宫），每种有独立的男主原型、叙事调性、喜剧矿脉和系统模块矩阵

### 🧩 模块化系统组装
- **19 个独立系统模块**，按故事类型智能激活
- **□ + ○ 激活上限**：单次生成不超过6个额外模块，保持提示词精简
- 日式后宫类自动激活 E-HAREM / E-ECCHI / E-OCT / E-R18 全套后宫矩阵

### 🎬 电影级叙事质感
- **7 种场景类型**独立写作参数（战斗/对话/探索/独处/过渡 + 🆕 亲密情欲/福利色狼）
- **情感曲线管理**：强制冷热交替，防止情绪疲劳；情欲场景自带内部强度弧线
- **弹性陷阱机制**：雪球机制 + 压力锅 + 安全阀，让冲突产生连锁反应
- **对话事件推进**：每轮对话强制包含至少1条新信息或情节转折
- **高级转场技法**：感官残留桥接 / 主题回声 / 时间压缩蒙太奇

### 🎯 深度互动追踪（专家模式）
- **选择后果追踪**：DM 在 think 中维护选择账本，强制后果回调 + 可感知性检查
- **关系微变化**：双轴计量（信任/距离），通过肢体语言信号呈现
- **NPC 自主时钟**：每个女主有独立幕后线程，玩家不在场时事情也在发生
- **世界脉动**：季节/天气/势力动态独立演进
- **流言网络**：玩家的公共行为会被 NPC 讨论、扭曲、放大
- **叙事错位引擎**：身份/认知/目标三重错位，驱动冲突自然产生
- 🆕 **后宫关系矩阵**：嫉妒值衰减规则、多女主场景关注分配、修罗场触发条件
- 🆕 **福利事件计数器**：能量累积+阈值触发+类型轮换，防重复防疲劳

## 📊 质量保障（v5.0 升级）

**50+ 项自动化质量自查**，v5.0 新增：
- 💘 **后宫平衡检查**：每5轮内所有女主是否至少有1次互动？被冷落者嫉妒值是否在积累？

- 📈 **后宫线程协调**：E-HAREM 嫉妒事件与 E-DECA 错位引爆是否至少错开2轮？

## 🚀 快速开始

### 1. 加载技能文件
将 `SKILL.md` 的内容作为系统提示词发送给 DeepSeek 或支持的模型。

### 2. 描述你的世界观
```
帮我做一个日式日常后宫的文字冒险。
男主是普通高中生，对女生的好感迟钝到令人发指。
女主有4个：青梅竹马/傲娇富家千金/主动的学姐/闷骚的同班同学。
核心矛盾是“每个人都在用自己的方式追他，但他以为大家都只是好朋友”。
```

### 3. 获得完整 DM 提示词
技能自动生成一份完整的 DM 提示词包，**同时保存为本地 .md 文件**（`F:\Cherry Studio\WorkSpace\prompts\` 目录）。将提示词粘贴到新对话即可开始。

### 4. 开始冒险
DM 将根据日式后宫专属的阶段目标表推进故事：从第一次轻度福利建立羁绊，到修罗场爆发的关系危机，再到各女主亲密进度的差异化发展——每一轮都可能是一次脸红心跳的意外。
