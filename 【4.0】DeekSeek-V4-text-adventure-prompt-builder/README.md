## 📖 这是什么？

**Text Adventure Prompt Builder** 是一个专为大型语言模型设计的**元提示词（Meta-Prompt）技能**。它不只是生成一份 DM 提示词——它更像一位资深叙事设计师，在接受你的世界观构想后进行“叙事编译”，交给你一整套可控、可演进、可沉浸的互动故事引擎。

v4.0 是这个技能的一次重要跃迁。如果说 v3.0 解决了“怎么写”，v4.0 回答了“写什么”——它新增了**故事蓝图引擎**和**冲突预算池**，让 DM 在每轮叙事前都清楚：下一步发生什么才精彩。

## 🧬 v4.0 新特性

### 🗺️ 故事蓝图引擎
直接从你的世界观推断出**核心戏剧问题**、**三幕结构**和**阶段目标节拍表**。DM 在启动游戏前就拥有了一份完整的故事弧线地图，不再“走一步看一步”。

### ⚡ 冲突预算池
每轮累积冲突能量——逃避选择、关系停滞、世界脉动都会增加预算。能量满10时**强制触发精彩事件**：情感突袭、外部入侵、伏笔引爆、关系暴露危机。彻底告别“日常-对话-选项”的无尽循环。

### 🎛️ 核心/专家双模式
不想面对复杂的叙事系统矩阵？**核心模式**默认开启，只保留6条不可削减的铁律规则——够轻量，够稳。想要世界在呼吸、NPC 在你看不到的地方密谋、错位轴在深处滋滋作响？**专家模式**等你来驾驭。

### 🎯 选择后果可感知性检查
每个历史选择的回调必须通过**三问测试**：关联到具体选项了吗？玩家不需回忆就能察觉吗？改变不可逆吗？确保每一个选择都有重量，玩家能“感觉到”世界在反应。

### 📝 首轮叙事蓝图 + 强制角色对话示例
抽象开场规则被转化为**5拍执行节拍**（感官锚定→情境建立→异常信号→角色出现→截止点），DM 照拍子填细节即可。每个女主角自带一句**开场典型台词**——不是描述，是可直接引用的一句话，确保第一轮互动就建立角色声音辨识度。

## ✨ 核心特性

### 🧠 全维度智能推断
- **四维推断引擎**：自动从用户描述中推断 `故事类型 × 文风配置 × 游戏体验 × 开场模式`
- **六维文风调色板**：叙事节奏 / 描写密度 / 抒情程度 / 幽默模式 / 成人描写 / 对话风格
- **八种故事类型**原生支持，每种有独立的男主原型、叙事调性、喜剧矿脉和系统模块矩阵

### 🧩 模块化系统组装
- **17 个独立系统模块**，按故事类型智能激活
- **□ + ○ 激活上限**：单次生成不超过6个额外模块，保持提示词精简

### 🎬 电影级叙事质感
- **5 种场景类型**独立写作参数（战斗/对话/探索/独处/过渡）
- **情感曲线管理**：强制冷热交替，防止情绪疲劳
- **弹性陷阱机制**：雪球机制 + 压力锅 + 安全阀，让冲突产生连锁反应
- **对话事件推进**：每轮对话强制包含至少1条新信息或情节转折
- **高级转场技法**：感官残留桥接 / 主题回声 / 时间压缩蒙太奇

### 🎯 深度互动追踪（专家模式）
- **选择后果追踪**：DM 在 think 中维护选择账本，强制后果回调 + 可感知性检查
- **关系微变化**：双轴计量（信任/距离），通过肢体语言信号呈现
- **NPC 自主时钟**：每个女主有独立幕后线程，玩家不在场时事情也在发生
- **世界脉动**：季节/天气/势力动态独立演进
- **流言网络**：玩家的公共行为会被 NPC 讨论、扭曲、放大
- **叙事错位引擎**：身份/认知/目标三重错位，驱动冲突自然产生

## 📊 质量保障（v4.0 升级）

**40+ 项自动化质量自查**，新增：
- 🔍 **情感浸润度检查**：每篇回复须满足至少2/5项感官与肢体语言指标
- 🗺️ **故事蓝图自查**：核心戏剧问题、三幕终点、阶段目标完整性
- 🎯 **后果可感知性自查**：过去5轮是否有至少1次可感知回调
- ⚡ **双模式一致性自查**：核心模式不混入专家模块
- 🕰️ **知识同步检查**：穿越/转生类故事是否从第一秒开始，无时间跳跃

## 🚀 快速开始

### 1. 加载技能文件
将 `SKILL.md` 的内容作为系统提示词发送给 DeepSeek 或支持的模型。

### 2. 描述你的世界观
```
帮我做一个仙侠类的文字冒险RP。
男主是穿到修真界的社畜程序员，靠信息差解构修仙法则。
女主有4个：冷淡师姐/腹黑师尊/小师妹/魔教圣女。
核心矛盾是“天赋至上论”与“降维打击”的冲突。
```

### 3. 获得完整 DM 提示词
技能自动生成一份完整的 DM 提示词包，**同时保存为本地 .md 文件**（`F:\Cherry Studio\WorkSpace\prompts\` 目录）。将提示词粘贴到新对话即可开始。

### 4. 开始冒险
DM 将根据你选择的核心或专家模式，按照故事蓝图、情感曲线、场景类型规则，为你呈现第一轮经过5拍结构精心设计的开场叙事。
