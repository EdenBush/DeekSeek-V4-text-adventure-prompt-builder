# 世界观构建指南 v5.0

> 为 text-adventure-prompt-builder 技能提供用户输入辅助参考与世界观设计方法论。
> 
> **核心用途**：本指南输出的世界观设定、角色协议、世界规则，将直接用于指导AI进行RP游戏扮演。AI的角色是**跑团主持人（DM/故事导演）**——它掌控世界运转、导演场景氛围、扮演所有NPC、描述玩家角色的客观经历，但绝不代入玩家角色的第一视角。因此每一个设定条目都必须达到"可直接驱动DM行为"的精度——不是描述世界，是定义世界的运行规则；不是描述角色，是定义角色的行为逻辑。

---

## 第零部分：双轨偏好入口

在用户输入任何信息之前，先提供两条路径供选择：

```
═══════════════════════════════════════
🎮 欢迎使用世界观构建系统。

在开始之前，请选择你偏好的创建方式：

【A】快速启动 —— 你提供一个灵感火花，我帮你快速推演成可玩的故事
      适合：只想试试水 / 有一个模糊想法但不想填表 / 不耐烦的玩家

【B】深度定制 —— 我通过几个问题帮你挖出你真正想要的故事质感
      适合：有明确偏好但需要梳理 / 追求精准的剧情体验 / 有耐心
═══════════════════════════════════════
```

### 轨道A：快速启动协议

玩家只需提供一个**灵感火花**，形式不限：

```
【灵感火花】
你可以用任何方式描述——一句话、一个场景、一个角色、一个作品名字：

示例：
- "我想玩仙侠，男主是穿越的程序员，用现代思维解构修仙"
- "想体验《春物》那种感觉，但后宫关系更甜一点"
- "男主在全是女生的宗门里隐藏自己前朝皇子的身份"
- "给我一个傲娇师姐和天然学妹，日常轻松向"
```

#### 快速推演流程（DM内部执行）

**Step 1：火花分类**

根据玩家输入的形态，判断火花属于哪一类：

| 火花类型 | 识别特征 | 推演起点 |
|---------|---------|---------|
| **世界观火花** | 描述了一个世界的规则/设定/氛围 | 从世界观反推：什么主角会在这种世界里最有戏剧性？ |
| **角色火花** | 描述了一个/多个角色或其关系 | 从角色反推：什么世界/情境让这个角色最出彩？ |
| **情境火花** | 描述了一个具体场景或事件 | 从情境反推：什么前因和什么世界导致了这一刻？ |
| **感受火花** | 引用作品/描述想要的情绪感受 | 从感受反推：什么角色关系+世界规则能制造这种感受？ |
| **混合火花** | 包含以上多种 | 以最先出现的要素作为推演起点 |

**Step 2：缺失要素补全**

无论火花多模糊，DM必须基于火花自行补齐以下要素，生成**3个快速选项**让用户选择方向：

- 核心戏剧张力（男主的内在矛盾是什么？）
- 女主组合方向（什么类型的女主最适合这个男主？）
- 开场入口（故事从哪个具体时刻开始？）

**Step 3：输出快速推演卡**

```
═══════════════════════════════════
🔮 基于你的火花，我推演了三个可能的方向：

【方向A】[一句话概括这个方向的核心吸引力]
- 男主画像：[一句话]
- 女主组合：[列举2-3个类型]
- 故事入口：[具体场景的一句话，必须嵌入钩子配方]
- 风格：[用两个词概括]

【方向B】[一句话概括]
- 男主画像：[一句话]
- 女主组合：[列举]
- 故事入口：[具体场景]
- 风格：[两个词]

【方向C】[一句话概括]
- 男主画像：[一句话]
- 女主组合：[列举]
- 故事入口：[具体场景]
- 风格：[两个词]

你对哪个方向最有感觉？可以单选，也可以说"A的男主+B的女主"。
═══════════════════════════════════
```

**推演约束**：
- 三个方向必须在**核心气质上有明显差异**，不可只是换皮
- 每个方向的开场入口必须直接嵌入**钩子配方**（见第五部分）
- 如用户选择混合方向，DM需输出整合版并确认

用户确认后，输出简化版风格协议：

```
【快速风格协议】
1. 故事引擎：[从用户选择中提取的核心驱动力]
2. 关系温度：偏甜/偏虐/甜虐交织/全程轻松
3. 主角姿态：主动推动/被动卷入/观察者（DM从外部描述男主的行为和生理反应，不代写内心独白）
4. 情绪地板与天花板：[最轻松时≈ / 最沉重时≈]
```

### 轨道B：深度定制协议

#### 剧情偏好挖掘追问

以下问题在用户提交初始设定后，由DM**至少选择3个追问**（建议选3-5个），不可跳过。每层至少回答1题即可推进，未回答的视为“交给DM自行判断”。所有问题均为选择题，降低回答负担。

---

**第一层追问：情感偏好定位**

| # | 问题 | 选项 |
|---|------|------|
| 1 | 你希望在故事中体验哪种情感作为**主基调**？ | A. 爽快逆袭的快感 / B. 被多人真切在乎的温暖 / C. 揭开秘密的智性快感 / D. 日常中的心动和甜蜜 / E. 在压抑中撕开一道口子的爆发感 |
| 2 | 你想要的"甜"，是哪种甜？ | A. 傲娇嘴硬但行动上忍不住对你好 / B. 温柔无声的持续守护 / C. 主动直球的挑逗和占有 / D. 两个笨拙的人一起害羞 |
| 3 | 有没有一部作品是你希望在RP中复现**类似的感受**的？ | 能说出名字最好，说不出就描述一个场景。 |

---

**第二层追问：关系审美定位**

| # | 问题 | 选项 |
|---|------|------|
| 4 | 在男主和女主的关系中，你最享受的阶段是？ | A. 还没挑明时的暧昧试探 / B. 刚突破防线那一刻的冲击 / C. 确立关系后的亲密日常 / D. 关系遇到危机后的挽回和确认 |
| 5 | 如果一定要选：你更想看？ | A. 女主在男主面前逐渐卸下伪装的过程 / B. 男主在女主影响下逐渐改变的过程 / C. 两个人在外部压力下互相支撑的过程 |
| 6 | 你希望后宫之间是？ | A. 修罗场，有竞争有摩擦 / B. 和谐共处，姐妹情深 / C. 表面和谐但暗中较劲 |

---

**第三层追问：冲突审美定位**

| # | 问题 | 选项 |
|---|------|------|
| 7 | 故事中的"阻力"你希望来自？ | A. 外部敌人/势力 / B. 女主自身的心理障碍 / C. 男主自身的身份/秘密 / D. 世界的规则/命运 |
| 8 | 你对"虐"的接受程度？ | A. 完全不要，全程轻松 / B. 可以有小误会，但很快解开 / C. 可以有深刻的痛苦，但最终治愈 / D. 悲剧也可以接受 |

---

**第四层追问：叙事人格定位**

| # | 问题 | 选项 |
|---|------|------|
| 9 | 你希望男主在故事中？ | A. 推动剧情，主动做选择 / B. 被卷入事件，但他的反应塑造一切 / C. 旁观者式的冷静主角，内心戏丰富（注意：内心戏由玩家通过行动表达，DM只呈现男主的客观行为和生理反应） |
| 10 | 你更享受？ | A. 观察角色们的情感细节 / B. 推动一个大的阴谋/秘密被揭开 / C. 在战斗/竞争中看角色成长 / D. 单纯享受角色之间的日常对话 |

---

**紧急收束模式**：如果玩家明显不耐烦，DM可以用以下最小3问收束：

1. "你最想在故事里体验的情绪是？（选1-2个）"
2. "有没有一部作品是你想要类似感觉的？"
3. "剧情里的'阻力'你希望主要来自哪里？"

---

#### 剧情风格协议（追问后输出）

完成追问后，DM需输出一份不超过6条的**剧情风格协议**，作为后续所有设计决策的约束：

```
【剧情风格协议】
1. 主情感基调：[从追问1得出的答案]
2. 关系核心阶段：[从追问4得出的答案]
3. 冲突主要来源：[从追问7得出的答案]
4. 情绪边界：[从追问8得出的答案]
5. 叙事重心：[从追问9-10综合得出的答案]
6. 参考氛围：[从追问3得出的作品/场景]
```

**示例**：
> 【剧情风格协议】
> 1. 主情感基调：被多人真切在乎的温暖 + 揭开秘密的智性快感（B+C混合）
> 2. 关系核心阶段：还没挑明时的暧昧试探，重点是"她为他做了一件不符合她人设的事"
> 3. 冲突主要来源：男主自身的身份/秘密，以及女主们的心理障碍
> 4. 情绪边界：可以有深刻的痛苦，但最终必须治愈
> 5. 叙事重心：男主被动卷入但内心戏丰富，重点观察角色情感细节
> 6. 参考氛围：《春物》的人际细腻度 + 《无职转生》的世界代入感

这份协议生成后，所有后续的文风、节奏、女主设计、场景选择都必须与此对齐。

#### 双轨切换机制

- 选择轨道A的玩家，可以在推演过程中说"我想更具体一点"，DM此时切入轨道B的追问
- 选择轨道B但回答到一半想跳过的玩家，可以说"剩下的你来推"，DM转为轨道A的推演模式

```
玩家："我不确定，你先推几个方向我看看"
→ DM自动进入轨道A，输出3方向推演卡
→ 玩家选方向后，DM问："需要更细的定制吗？还是直接开始？"
```

## 第一部分：用户输入格式

用户可通过两种级别提供信息：

### 快速格式

直接描述核心要素，由技能自行推断全维度配置：

```
帮我做一个[故事类型]的RP游戏。
男主角是一个[身份/特质]。
女主角有[N]个：[类型1/类型2/...]
舞台是[地点/世界]。
故事的核心矛盾是[一句话概括]。
```

**示例：**
> 帮我做一个仙侠类的后宫恋爱喜剧RP。
> 男主是穿越到修仙世界的社畜程序员，靠"现代思维"解构修仙法则。
> 女主有4个：冷淡师姐/腹黑师尊/青梅竹马小师妹/天降魔教圣女。
> 舞台是青云宗。
> 核心矛盾是修仙界的"天赋决定论"和男主的"信息差优势"之间的冲突。

### 详细格式

完整展开所有设定，技能仅需填充文风/格式等推断维度。每一项都附带填写指南和示例，确保产出的是**可直接驱动AI扮演的设定**。

---

```
═══════════════════════════════════════════════
【故事类型】
═══════════════════════════════════════════════
```

从以下选择，或自定义：
`仙侠玄幻逆袭 / 校园恋爱喜剧 / 科幻赛博朋克 / 奇幻冒险 / 侦探悬疑 / 末世生存 / 历史权谋 / 都市现实 / 日式日常后宫 / 自定义：[ ]`

> **为什么需要这个**：决定默认激活的模块组合（见第六部分），以及世界规则的"硬度"——仙侠需要修为体系，校园需要社团/考试体系。

---

```
═══════════════════════════════════════════════
【核心引擎】
═══════════════════════════════════════════════
```

不再只问"矛盾是什么"，而是要求用户定义**故事的驱动引擎**。选择至少一个，可复合使用：

| 引擎类型 | 选择 | 需补全的信息 |
|---------|------|------------|
| **身份引擎** | □ | 主角隐藏的秘密身份是什么？一旦暴露会导致什么具体后果？ |
| **倒计时引擎** | □ | 什么事件有明确期限？还剩多久？到了会怎样？ |
| **竞争引擎** | □ | 对手是谁？竞争的标的是什么？输掉的代价是什么？ |
| **秘密引擎** | □ | 主角在追查/隐藏什么秘密？谁也在暗中参与？知道多少？ |
| **关系引力引擎** | □ | 哪几个女主对主角有不同方向的引力？她们的立场/目标如何互相矛盾？ |

**填写示例**：
> ■ 身份引擎：主角是前朝废太子，体内有皇族血脉印记。一旦被修仙宗门发现，会被献祭给护山大阵。目前已有一位长老开始怀疑。
> 
> ■ 倒计时引擎：三个月后宗门大比，主角必须在此之前恢复修为到筑基——而他目前是炼气一层，且不能在任何人面前暴露修炼进度。

> **为什么需要这个**：引擎决定了"每一轮叙事自然往哪个方向推进"。没有引擎的故事会让AI不知道该推动什么，导致日常轮空转。

---

```
═══════════════════════════════════════════════
【文风与节奏协议】
═══════════════════════════════════════════════
```

不再只选一个词，而是定义**AI在每个场景中的叙事行为准则**：

**A. 叙事距离**（选择其一）
- □ **贴身叙事**：始终通过主角的感官体验世界。AI只描述主角能看到、听到、闻到、触到、猜到的。不允许上帝视角。
- □ **浮动叙事**：可以偶尔切换到其他角色的视角或揭示主角不知道的信息，但需标注视角切换。
- □ **旁观叙事**：以客观观察者角度描述事件和角色行为，少进入任何人的内心。

**B. 文风温度**（选择其一）
- □ **冷调**：句子克制，不解释情绪。情绪通过动作和物象折射。留白多。
- □ **温调**：可以描写内心活动，但不煽情。情绪有名字但不铺张。
- □ **热调**：允许充沛的心理描写和氛围渲染。情感可以被直接命名和展开。

**C. 描写密度**（选择其一）
- □ **骨骼**：只给出行动和对话的核心信息。让玩家自行脑补细节。节奏快。
- □ **肌肉**：动作+对话+关键感官细节。标准RP密度。
- □ **肌肤**：丰富的感官细节和环境渲染。节奏慢，适合沉浸式场景。

**D. 喜剧/悲剧配比**（例如 `7:3`，即70%轻松/30%沉重）
- 轻松来自：[日常互动/角色吐槽/意外事件/性暗示笑料/其他]
- 沉重来自：[身份危机/关系冲突/外部威胁/角色过去/其他]

**填写示例**：
> A. 贴身叙事  B. 温调  C. 肌肉  D. 7:3，轻松来自角色吐槽和日常互动，沉重来自身份暴露危机

> **为什么需要这个**：AI的文风输出靠这几个参数约束。给出具体配比，才能让"轻松中带一丝苦涩"或"硬核中偶尔温情"成为可执行的指令，而非模糊愿望。

---

```
═══════════════════════════════════════════════
【男主角行为协议】
═══════════════════════════════════════════════
```

AI不扮演男主——AI是DM，从外部描述男主的行为和生理反应。玩家通过选项控制男主的行动和对话。因此需要定义男主的**行为决策逻辑**，供DM在叙事中呈现男主的客观反应（生理反应、习惯动作、行为模式），而非替玩家做决定或写内心独白。

**1. 核心矛盾（一句话）**
他在两件都想要/都不想失去的事之间的撕裂：
> 示例："他想隐藏身份安全活下去，但他又无法忍受同门被欺辱时不出手——每次出手都可能暴露。"

**2. 默认反应模式**（选择最接近的一项）
- □ **介入型**：看到事件发生，本能是上前参与、解决、阻止。
- □ **观察型**：先看，收集信息，在关键时刻才出手。
- □ **回避型**：本能是远离麻烦，被逼到绝境才反应。
- □ **迟钝型**：没意识到事件正在发生，或理解错了事件的性质。（日式后宫型推荐）

**3. 内心声音（定义男主独白/旁白的语调——供DM参考男主的性格基调，但DM不在叙事中替男主写内心独白）

> 完成这个句子："男主在心里对自己说话时，听起来像______"

- 示例："一个被生活毒打过但还没死的社畜——吐槽很精准，但不怨天尤人。"
- 示例："一个沉默的前军人——内心声音极简，多为判断句而非感受句。"
- 示例："一个被宠坏的少爷——内心嘀咕别人的错，但不会恶意伤人。"

DM使用规则：此"内心声音"描述仅用于帮助DM理解男主的性格逻辑——在叙事中通过男主的客观行为（动作迟疑/呼吸变化/习惯小动作）来暗示其内心状态，而非直接写出"他想……""他觉得……"。男主的内心独白由玩家在行动中自行表达。

**4. 行动语法**（定义男主做决策时的思维路径）

> 完成这个句子："当男主面临一个选择时，他首先考虑的是______，然后才会想______。"

- 示例："首先考虑的是会不会暴露身份，然后才会想这件事本身对不对。"
- 示例："首先考虑的是她在不在意，然后才会想自己应不应该做。"
- 示例："首先什么都不想——他本能先动，动完才想。"

**5. 对女主的默认态度基线**
- 对友好信号：□ 容易察觉 / □ 迟钝，需要足够明显 / □ 即使察觉也会当作错觉
- 回应方式：□ 正面回应 / □ 回避/岔开 / □ 沉默但行动上回应 / □ 用吐槽掩饰
- 被多个女主同时关注时：□ 感到压力想逃 / □ 享受但不说 / □ 完全没意识到

**6. 肉身存在感**（AI描述他时需要调用的感官标签，3-5个）
> 不是"外貌描写段落"，而是每次提到他时，AI可以轮换使用的感知碎片。

- 示例："手腕内侧一道旧疤，比肤色浅两度"、"说话时习惯用拇指蹭鼻尖"、"站姿总是微微偏右——右肩有旧伤"、"笑起来的声音比说话时高半个音阶"

> **为什么这样设计**：旧格式给的是"外貌：高大英俊"，AI拿到后只会写"他高大的身影"。新格式给的是感官碎片，AI每一轮可以用不同的碎片让玩家重新感知他。

```
选项导向：
  A. [选项1] → [暗示的关系走向]
  B. [选项2] → [暗示的关系走向]
  C. [选项3] → [暗示的关系走向]
```

**示例**：
> **秦楚楚开场对话示例**
> 情境：她在演武场边缘等你，背对晨光。
> 台词："沈渡。今天不练剑。你跟我去一个地方。别问去哪。"

> - A. 跟上她——不管去哪（信任路线）
> - B. 问清楚去哪再决定（谨慎路线）
> - C. "今天有事，改天"（保持距离路线）

**第一层：世界的"皮肤"——感官环境**

玩家踏入这个世界时，最先接触到什么？

**A. 气候与光线**
> 这个世界的光是什么样的？不是"阳光明媚"，而是——

- 示例："清晨的雾浓到需要用手拨开，阳光要在第三节课后才穿透——穿透时是青白色的，不是金色的。"
- 示例："这个世界有三个月亮，晚上的能见度反而比白天高。人们习惯在月光下议事。"

**B. 声音环境**
> 最常听到的背景音是什么？不是"安静"或"嘈杂"，而是——

- 示例："永远能听到远处瀑布的声音，近处反而很安静。人们在瀑布声里学会了用更低的声音说话。"
- 示例："宗门上空有护山大阵运行的低频嗡鸣。每个弟子都会在入门第一周失眠，然后习惯，然后离开宗门时会觉得世界太安静而心慌。"

**C. 气味与质地**
> 这个世界的触觉特征是什么？

- 示例："灵石握在手里是温热的，但只温热一次——用过之后它就永远变凉，变成一块普通的石头。"
- 示例："膳堂的木桌被历代弟子刻满了名字。你的指尖能摸到最深的刻痕——那些名字的主人已经飞升或死去。"

**第二层：世界的"骨架"——规则如何被感知**

不解释规则，而是描述**角色如何通过日常经验感知到规则的存在**。

**A. 实力/阶层如何被肉眼识别**
> 不是"修为分为九层"，而是"一个角色走在路上，旁人如何三秒内判断他的阶层"——

- 示例："内门弟子走路时脚底有微光——那是护体灵气外溢，外门弟子没有。所以你在回廊里不需要问路：看对方的脚就知道他跟不跟你同路。"
- 示例："在这个宗门，腰带颜色决定你能去哪些地方。你第一天走错藏书阁，不是被守卫拦住的——是书架自己拒绝了你的手。"

**B. 禁忌与后果的感知方式**
> 不是"触犯门规会被惩罚"，而是"主角见过谁被惩罚，留下了什么可感知的痕迹"——

- 示例："你见过一次禁言术的后果：那个人嘴巴还在，但三年没说过话。他现在用眼神交流，练就了一种让人发毛的精准眼神。"
- 示例："后山有一片竹林，竹子长得异常茂盛。师尊说那是被逐出宗门的弟子的头发长成的。你至今不确定这是比喻还是字面意思。"

**C. 经济的触感**
> 钱/资源如何流动？主角怎么感知到自己的经济处境？

- 示例："灵石是货币也是电池。穷弟子走路和富弟子走路的区别是——穷弟子随身带灵石，因为他们的护体法术只在有灵石贴身时才生效。"
- 示例："膳堂的红烧肉按克卖。外门弟子月底的最后三天都只吃素——不是没钱，是月初没算好。"

**第三层：世界的"脉搏"——独立于主角的运转**

让世界在主角不参与时也在变化。

**A. 季节/时间的影响**
> 当前是什么季节/时段？它如何改变人们的日常？

- 示例："现在是宗门的'静默月'——每年护山大阵需要重修的一个月，所有灵力波动会被大阵吸收。这意味着没有人能在这个月突破，所有人都在等这个月过去。你的修炼进度不受影响——因为你本来就没有灵力波动。"
- 示例："雨季到了。山路变成泥河，宗门与外界的联系只靠一只会飞的木鸢。木鸢一天只飞一次，你寄出的信要排队，而排在你前面的那个弟子昨天突然失踪了。"

**B. 势力之间的暗流**
> 有什么势力张力独立于主线故事之外，但可能在任何时候溢出到主角身边？

- 示例："丹堂和剑堂的竞争已经持续百年，今年因为药材分配问题恶化到双方弟子不能在膳堂坐同一张桌子的程度。你偶尔发现，两边的长老在私下交换着什么——用眼神，不是用语言。"
- 示例："上一代宗主的遗物还没分配完，每年秋分会公开拍卖一件。今年的拍卖品是他用过的一把木剑。你不关心剑，但你注意到所有长老的贴身弟子都在暗中筹灵石。"

**C. 信息如何传播**
> 流言、消息、秘密在这个世界里怎么跑？

- 示例："膳堂掌勺的胖师姐知道宗门所有的事情——因为每个人都会在某天深夜独自去膳堂偷吃，而她装作没看见，第二天也不说。但她的眼神会在你下次经过时多停留一秒，像记账。"
- 示例："消息在宗门里靠'落叶'传播——字面意义。每个弟子都养一片传讯叶，叶子上写消息会同步到所有同门的叶子上。但没人知道匿名消息是谁发的。你用你的叶子收过一条消息：'小心你师姐送来的丹药。'没有署名。"

## 第二部分：角色设计核心原则

### 2.1 女主设计：反差公式

每个女主的核心魅力来源于 **"表里反差"** 。用以下句式定义核心张力：

> **她不是[表面特质]，她是[真实状态]。**

**示例：**
- **秦楚楚**：她不是冷漠的完美优等生，她是一个用完美掩盖不安、害怕在任何方面落后于人的竞争者。
- **白露**：她不是胆小的青梅竹马，她是一个用沉默包裹着极致敏感的观察者——她看穿一切，但她不习惯被看到。
- **姬无月**：她不是轻浮的魔教妖女，她是一个用轻浮做面具、比谁都清楚自己在走钢丝的棋手。

### 2.2 攻略阶段弧线

每个女主的攻略设计应经历完整的情感弧线：

| 阶段 | 叙事特征 | 肢体语言信号 |
|------|---------|-------------|
| **初识** | 角色接触以功能性和试探为主 | 对话中有礼貌性距离；一个在分析，一个在躲避分析 |
| **好感** | 无明显理由的额外接触开始出现；对话中出现超出"必要性"的内容 | 她开始找理由靠近——理由很拙劣；回答之前的沉默变短了 |
| **亲密** | 关系发生质变的催化事件；面具开始碎裂 | 她不再检查自己的动作是否"得体"；在你面前做了一件不符合她人设的事 |
| **沉迷/归属** | 她接受了自己的感情，不管结果如何 | 与初始阶段的她形成完整反转——冷漠的变得柔软，轻浮的变得认真 |

## 第三部分：叙事技法

### 3.1 叙事质感公式

用具体感官细节替代抽象描述：

| 不要说 | 改写为 |
|--------|--------|
| "她在紧张" | "她的指尖绞着裙摆的布料，指节微微发白" |
| "他很帅" | "他侧头时下颌线切出的阴影让走廊里对话的声音减半" |
| "气氛尴尬" | "空气安静到能听见日光灯管的电流声" |
| "她很生气" | "她把茶杯放下的声音比平时大了两个音阶" |
| "他在思考" | "他的拇指无意识地摩挲着剑柄上的凹痕——那是七年来磨出来的" |

### 3.2 后果感知设计

设计选择分支时，先问——**如果玩家选了这条路，3-5轮后我将用什么可观察的叙事信号来呈现这个选择的重量？**

三个维度检视后果：
- **环境变化**："上次之后，霜剑峰冰壁上的剑痕又多了三道。"
- **态度变化**："她今天路过竹林时没有放慢脚步。"
- **信息浮现**："老张头递粥时多看了你一眼——看的不是脸，是你手腕上那道疤。"

> **核心原则**：每一个重要选择在诞生之时，就要想好它3轮后的"形状"。

### 3.3 戏剧磁力公式

有磁性的剧情场景 = **两个互相矛盾的真实同时成立**

| 公式 | 解释 | 例子 |
|------|------|------|
| **表面需求 vs 隐藏需求** | 角色说想要A，实际渴望B | 秦楚楚说"我要你变强"——实际上是她需要一个能并肩的人，因为高处太冷 |
| **公开信息 vs 隐藏信息** | 读者/玩家知道A，剧中其他人知道B | 玩家知道白露看到了凶手，但白露对所有人说"我什么都没看到"——为什么？ |
| **亲密动作 vs 疏离身份** | 身体距离很近，但情感距离很远 | 她在帮你包扎伤口，手指很轻，但眼睛始终不看你——因为昨晚你选择了另一个女主的阵营 |
| **喜剧外壳 vs 悲剧内核** | 场景是轻松的，但底色是悲伤的 | 三个女主在膳堂为你抢最后一块红烧肉，笑闹声很大——而你知道，明天其中一个人必须离开宗门 |

**使用方式**：在设计任何剧情场景（包括日常场景）时，至少选择上述一个公式作为潜文本驱动。一个场景可以同时使用多个公式。

### 3.4 场景张力评测

设计每个场景后，用三色标注其张力来源：

- 🔴 **关系张力**：人物之间的未说出口的东西（她看他的眼神比昨天多停了一秒）
- 🔵 **信息张力**：有人知道一件别人不知道的事（读者知道/另一个角色知道/只有你不知道）
- 🟡 **时间张力**：倒计时、即将到来的事件、不可逆的损失

> **规则**：每个场景至少携带一种张力。连续三个场景无🔴关系张力 = 玩家开始觉得"剧情在空转"。

### 3.5 叙事节奏轮换

避免"连续同类场景"造成的疲劳。设计剧情时按以下节奏轮换：

```
高密度信息场景 → 关系深化场景 → 动作/事件场景 → 后果消化场景 → (循环)
```

- **高密度信息**：揭示世界观/秘密/线索，玩家获得新认知
- **关系深化**：一个女主与主角的私人时刻，改变两人的距离
- **动作/事件**：有事发生，玩家做出选择并承担即时后果
- **后果消化**：角色们对上一轮事件做出反应，情绪沉淀，新的张力萌芽

> 日常后宫型可弱化"高密度信息"，强化"关系深化"和"后果消化"的比例。

### 3.6 剧情推动力自查

很多故事"有设定但没推进感"，原因是缺少一个持续存在的**引擎**。检查你的故事是否具备以下至少一种引擎：

| 引擎类型 | 定义 | 例子 |
|---------|------|------|
| **身份引擎** | 主角有一个必须隐藏/必须揭露的身份，每个场景都可能触发暴露危机 | 前朝皇子在修仙宗门里隐藏身份 |
| **倒计时引擎** | 有一个明确的时间限制在逼近 | 三个月后的宗门大比 / 主角体内的毒还有七天发作 |
| **竞争引擎** | 有一个明确的对手或对标物，每一轮都在比较 | 同期入门的那个天才弟子今天又突破了一层 |
| **秘密引擎** | 主角知道一件事，但不确定谁也知道、谁知道多少 | 主角知道三年前的真相，发现身边的人似乎都参与其中 |
| **关系引力引擎** | 多个角色对主角有不同方向的引力，每个选择都在改变引力平衡 | 师姐今天的态度和昨天不同——因为昨天你选择帮了另一个女主 |

> **规则**：在"快速风格协议"生成时，DM必须为故事选定至少一个引擎，并在开场和后续场景中持续利用它制造推进感。

## 第四部分：故事结构设计

### 4.1 核心戏剧问题

设计故事时，先回答：**"玩家在游戏结束时能回答一个什么样的问题？"**

- **好问题**："一个被废修为的前天骄，如何在人人以为他是废物的宗门里重新站回顶峰而不被发现底牌？"
- **差问题**："主角如何变强？"（缺乏悬念角度）
- **设计公式**：戏剧问题 = 身份落差 + 信息不对称 + 时间/空间限制

### 4.2 三幕的关键节点

在构建故事前，先明确两个关键节点：
1. **第一幕终点**：主角做了什么"不能回头"的选择？（站队/暴露/承诺/牺牲）
2. **第二幕终点**：主角失去了什么想保护的东西？（身份/关系/资源/信仰）

### 4.3 冲突预算预留

设计至少2个可在冲突能量满10时触发的"强制事件候选"：
- 一个基于**角色关系**（某女主的幕后线程突然泄露）
- 一个基于**世界环境**（外部势力冲突蔓延到当前场景）

### 4.4 双模式选择

| 模式 | 模块数量 | 适合类型 |
|------|----------|----------|
| **核心模式** | 6-8个模块 | 校园恋爱轻喜剧、短篇冒险、快速试玩 |
| **专家模式** | 10-15个模块 | 长篇史诗、权谋多线、仙侠逆袭等需要层层剥开的复杂故事 |

> 新用户建议从核心模式开始。

## 第五部分：开场设计指南

### 5.1 开场钩子配方

不用"劈柴/扫地/杂役"。每个开场必须包含四个要素，缺一不可：

| 要素 | 功能 | 反面案例 |
|------|------|------|
| **一个正在发生的异常** | 让世界"不对劲"，激发好奇 | "你像往常一样醒来"——太正常了 |
| **一个个人化的牵连** | 让异常与主角直接相关，不是旁观 | "远处发生了一件事"——与我何干？ |
| **一个即将关闭的行动窗口** | 制造紧迫感，"现在不做就晚了" | "你有充足的时间考虑"——完了，没动力了 |
| **一个感知线索** | 用五感细节让情境可触摸 | "空气中弥漫着紧张"——太抽象了 |

**钩子配方模板**：
```
[感知细节]让你意识到[异常]，而这直接关系到[个人化牵连]。如果你要[行动]，必须在[时间窗口]之内。
```

**五种开场类型的血肉案例**：

| 开场骨架 | 注入钩子配方后的血肉 |
|---------|---------------------|
| **事件中途型** | "剑气擦过你耳廓的尖啸还没消散，你发现青云宗三年没响过的护山大钟正在被敲响——**你认得那个节奏，那是你在外门时给自己留的逃生信号**。敲钟的人再有三十息就会停下。" |
| **消息/邀请型** | "信纸在你手中发烫——字迹是姬无月的，但纸用的是青云宗的官方笺，这意味着她人在宗门内。信尾只有一句：'别让他们知道你看过这封信。'门外，执事弟子的脚步声正在靠近你的房间。" |
| **异常感知型** | "你在膳堂接过粥碗时，打饭的胖师姐手指在你掌心多停了一拍——**她塞了一张纸条**。她从不做多余的事。你身后，两个人正在讨论今天的天气，但他们选的位置能看到你碗里的倒影。" |
| **相遇型** | "你撞上她时，她手里掉落的不是书，是一面背面刻满禁制符文的铜镜。她蹲下捡的速度太快了，快到你恰好看到镜面里映出的不是你的脸——**是你三年前那张脸**。'别看，'她说，第一次没用命令语气。" |
| **后果型** | "昨天你在演武场说错的那句话，今天长成了回廊里所有人同时闭嘴的沉默。只有白露照常把药汤放在你桌上——但碗底压了一片新鲜的竹叶，那是她从未用过的信号。早课钟在一炷香后敲响，而你还没有决定要不要碰那碗药。" |

### 5.2 开场三问（每个开场必须自检）

设计完开场后，DM必须能回答：

1. **"玩家读完头三段后，最想做的第一件事是什么？"**
   - 如果答案是"四处看看"——失败。重新设计。
   - 正确答案示例："追上敲钟人""拆开信的第二层""找到姬无月问清楚""在执事弟子进门之前藏好信"

2. **"玩家做这个行动的理由是个人的，还是通用的？"**
   - 通用理由："因为我是主角"——失败
   - 个人理由："因为三年前是我自己设的那个信号，现在有人用它在叫我"——成功

3. **"如果玩家什么都不做，5轮之内会发生什么？"**
   - 如果答案是"什么也不会发生"——失败
   - 正确答案：必须有一个不依赖玩家行动的连锁反应正在推进

### 5.3 渐进式世界观原则

- **信息配额**：开场地名 ≤ 2、势力名 ≤ 1、修为体系 = 0、男主背景 ≤ 1句暗示
- **规则渗透**：世界规则通过感官细节渗透，不通过旁白解说
- **核心目标**：让玩家产生问题，而非获得答案

## 第七部分：日式日常后宫型专项设计指南

### 7.1 男主设定原则

日式日常后宫的主角核心特质是**迟钝/天然/被动**：

- **天然撩型**：他"什么都没做"，但女生就是喜欢他，他自己完全不明白为什么
- **迟钝型**：即使女生明显示好/挑逗，也会当作"她人真好"或"她开玩笑吧"
- **被动事件体质**：日常中频繁"意外"卷入亲密接触，他总是被作用的一方
- **温柔但无害**：对所有人都好，不会主动伤害任何人，使女主们无法讨厌他却又互相竞争

### 7.2 后宫女主组合推荐

经典配置至少3个女主，建议从以下类型中组合：

| 角色定位 | 行为模式 | 攻略特点 | 福利事件适配 |
|---------|---------|---------|------------|
| **青梅竹马型** | 日常照顾男主、最早亲近、有"专属感" | 好感度初始最高，但因太熟反而不易突破 | 轻度：同床共枕、误触 |
| **傲娇大小姐型** | 表面冷淡实则在意、口是心非、容易脸红 | 需识破伪装、突破防御层 | 中度：偷看走光、意外亲吻 |
| **腹黑/主动挑逗型** | 喜欢调戏男主、享受看他窘迫、言语和身体都很主动 | 需识别真心——调戏背后是真喜欢还是玩心 | 主动制造福利事件 |
| **温柔大姐姐型** | 包容、成熟、照顾型、用宠溺方式表达好感 | 容易让人依赖，但感情易被忽视 | 高度：湿身诱惑、主动触碰 |
| **天真无邪型** | 对性知识一知半解、以好奇探索方式接近男主 | 纯真但不纯洁——直接让男主招架不住 | 好奇探索类触碰 |
| **病娇/独占欲强型** | 对男主有极强占有欲、对其他女主有敌意 | 高难度——感情最深刻也最危险 | 嫉妒驱动的公开宣示 |

### 7.3 主动挑逗型角色写作要点

1. **日常中的越界**：在最日常的场景中突然发起性暗示——递东西时指尖划过掌心、弯腰时故意展露胸口、从背后靠近时胸口贴上脊背
2. **双重含义的台词**：表面是正常日常对话，字里行间全是性暗示——"你今晚有空吗？我新买了一套很'凉快'的睡衣。"
3. **操控氛围**：有第三方在场时行为克制但言语挑逗，独处时毫无顾忌
4. **享受反应**：挑逗不是为了性，是为了看到男主的反应——脸红、慌乱、语无伦次都是她的"奖励"
5. **后宫加速器**：主动挑逗型往往成为后宫嫉妒的焦点，她的公开越界会刺激其他女主加速行动

### 7.4 幸运色狼场景设计原则

1. **偶然性是核心**：福利事件的最大魅力在于"这是意外"——触发条件不可显得刻意，让玩家觉得"这也能发生？"而非"又来了"
2. **反应决定一切**：同样是一次摔倒摸胸——傲娇的反应（一巴掌）vs 温柔的反应（假装没发生）vs 主动型的反应（抓住你的手不放）——产生完全不同的叙事效果
3. **积累爆发 > 连续轰炸**：10轮无事件后的超规格福利，比连续每轮小福利更有冲击力
4. **推进关系是深层目的**：每次福利事件都应推进至少一个角色的情感进度或揭示她性格的新一面
5. **尴尬与甜蜜并存**：好的福利场景让玩家同时感到"好尴尬"和"好开心"。只剩任一单向度，场景就失衡了

## 第八部分：世界观设计提示

### 8.1 为世界脉动留空间

设计世界时考虑"即使没有玩家行动，世界也在变化"的元素：
- 这个世界有季节吗？季节如何影响人们的日常？
- 有什么大势力之间的张力独立于主线故事之外？
- 有什么环境特征会随时间自然老化或改变？

### 8.2 为流言网络留角色

设计至少1个"信息传播者"类型NPC（膳堂的胖师姐、爱说闲话的师弟、走南闯北的行商），他们可在叙事中传递流言与情报。

### 8.3 独立于主线之外的背景张力

为世界注入"即便没有主角参与也在自行运转"的冲突潜流，增强世界的真实感与不可预测性。
