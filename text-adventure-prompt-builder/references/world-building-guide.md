# 世界观构建指南

> 为 text-adventure-prompt-builder 技能提供用户输入辅助参考。

---

## 用户输入格式

用户可以提供两种级别的信息：

### 快速格式

直接描述核心要素，由技能自行推断全维度配置：

```
帮我做一个[故事类型]的RP游戏。
男主角是一个[身份/特质]。
女主角有[N]个：[类型1/类型2/...]
舞台是[地点/世界]。
故事的核心矛盾是[一句话概括]。
```

示例：
```
帮我做一个仙侠类的后宫恋爱喜剧RP。
男主是穿越到修仙世界的社畜程序员，靠"现代思维"解构修仙法则。
女主有4个：冷淡师姐/腹黑师尊/青梅竹马小师妹/天降魔教圣女。
舞台是青云宗。
核心矛盾是修仙界的"天赋决定论"和男主的"信息差优势"之间的冲突。
```

### 详细格式

完整展开所有设定，技能只需填充文风/格式等推断维度：

```
【故事类型】仙侠玄幻逆袭 / 校园恋爱喜剧 / 科幻赛博朋克 / 奇幻冒险 / 侦探悬疑 / 末世生存 / 历史权谋 / 都市现实
【游戏体验偏好】剧情驱动 / 探索驱动 / 关系驱动 / 动作驱动
【文风偏好】诗意 / 冷峻 / 轻松搞笑 / 黑暗沉重 / 硬核写实 / ...
【世界观】[详细描述世界的规则、历史、社会结构]
【核心矛盾】[故事的核心冲突和戏剧张力]
【男主角】
  - 姓名 / 假名：
  - 年龄 / 身份：
  - 外貌：
  - 性格与行为准则：
【女主角阵营】
  - 女主1：[姓名/身份/外貌/表面性格/真实性格/对男主态度/行为特征/说话方式]
  - 女主2：...
  - 女主3：...
  - 女主4：...
【次要角色】
  - NPC1：[姓名/身份/作用]
  - NPC2：...
【故事舞台】
  - 主舞台：[描述]
  - 关键地点：[列表]
【开场构想】[希望从什么情境开始]
```

## 写作原则

### 女主设计：反差公式

每个女主的核心魅力来源于"表里反差"。用以下句式定义：

> 她不是[表面特质]，她是[真实状态]。

示例：
- 秦楚楚：她不是冷漠的完美优等生，她是一个用完美掩盖不安、害怕在任何方面落后于人的竞争者。
- 白露：她不是胆小的青梅竹马，她是一个用沉默包裹着极致敏感的观察者——她看穿一切，但她不习惯被看到。
- 姬无月：她不是轻浮的魔教妖女，她是一个用轻浮做面具、比谁都清楚自己在走钢丝的棋手。

### 叙事质感公式

```
不说"她在紧张" → 写"她的指尖绞着裙摆的布料，指节微微发白"
不说"他很帅"   → 写"他侧头时下颌线切出的阴影让走廊里对话的声音减半"
不说"气氛尴尬" → 写"空气安静到能听见日光灯管的电流声"
不说"她很生气" → 写"她把茶杯放下的声音比平时大了两个音阶"
不说"他在思考" → 写"他的拇指无意识地摩挲着剑柄上的凹痕——那是七年来磨出来的"
```

### 攻略阶段弧线

每个女主的攻略设计应经历完整的情感弧线：

| 阶段 | 叙事特征 | 肢体语言信号 |
|------|---------|-------------|
| **初识** | 角色接触以功能性和试探为主 | 对话中有礼貌性距离，一个分析一个躲避分析 |
| **好感** | 无明显理由的额外接触开始出现；对话中出现超出"必要性"的内容 | 她开始找理由靠近——理由很拙劣；回答之前的沉默变短了 |
| **亲密** | 关系发生质变的催化事件；面具开始碎裂 | 她不再检查自己的动作是否"得体"；在你面前做了一件不符合她人设的事 |
| **沉迷/归属** | 她接受了自己的感情，不管结果如何 | 与初始阶段的她形成完整反转——冷漠的变得柔软，轻浮的变得认真 |

### 角色声音差异化

确保玩家不看标签就能分辨谁在说话：

| 角色 | 句长 | 称呼 | 语气词 | 句式 | 话题 |
|------|------|------|--------|------|------|
| 秦楚楚 | 中短句 | 直呼"沈渡" | 零 | 命令式为主 | 战斗/竞争 |
| 白露 | 极短句 | 不称呼 | 偶尔"的" | 陈述 | 日常 |
| 姬无月 | 中长句 | 昵称"天才君" | 高频"嘛/呢" | 反问多 | 一切 |

## v2.5 新增：开场设计指南

### 五种强制开场类型

不用"劈柴/扫地/杂役"——从以下五种中选择：

1. **事件中途型**：从事件进行中开始，玩家被抛入情境
2. **消息/邀请型**：一封信/信物/召唤启动故事
3. **异常感知型**：从正常逐渐滑向异常，有层次感
4. **相遇型**：与一个特定角色的初次接触
5. **后果型**：开场是主角之前某个行动的结果

### 渐进式世界观原则

- 开场信息配额：地名≤2、势力名≤1、修为体系=0、男主背景≤1句暗示
- 世界规则通过感官细节渗透，不通过旁白解说
- 让玩家产生问题而非获得答案

## v3.0 新增：模块选择速查

根据故事类型，以下系统默认激活或排除：

| 故事类型 | 额外激活的□模块 | 默认排除的○模块 |
|---------|---------------|---------------|
| 校园恋爱 | E-OCT, E-TRANS, E-RUMOR | E-NOV, G-PLOT, E-PULSE |
| 仙侠逆袭 | 全部□(5个) | 无 |
| 赛博朋克 | E-NOV, G-PLOT, E-PULSE | E-OCT, E-TRANS, E-RUMOR |
| 奇幻冒险 | E-NOV, G-PLOT, E-PULSE | E-OCT, E-TRANS, E-RUMOR |
| 侦探悬疑 | E-NOV, G-PLOT, E-TRANS, E-RUMOR | E-OCT, E-PULSE |
| 末世生存 | E-NOV, E-PULSE | E-OCT, G-PLOT, E-TRANS, E-RUMOR |
| 历史权谋 | 全部□(5个) | 无 |
| 都市现实 | E-OCT, E-TRANS, E-RUMOR | E-NOV, G-PLOT, E-PULSE |

□+○激活上限 = 6个，超限时按优先级裁剪：E-OCT > E-PULSE > E-RUMOR > E-TRANS > E-NOV > G-PLOT

> ⚠️ **注意**：仙侠逆袭和历史权谋的□模块已全部默认激活（5个），用户自行追加○模块时请勿超过1个，否则将超出6个上限。如确实需要追加多个，必须按优先级裁剪已激活的□模块。

## v4.0 新增：故事蓝图设计提示

### 核心戏剧问题
设计故事时，先回答：**"玩家在游戏结束时能回答一个什么样的问题？"**
- 好问题："一个被废修为的前天骄，如何在人人以为他是废物的宗门里重新站回顶峰而不被发现底牌？"
- 差问题："主角如何变强？"（没有悬念角度）
- 技巧：戏剧问题 = 身份落差 + 信息不对称 + 时间/空间限制

### 三幕的终点事件
在构建故事前，先明确两个关键节点：
1. **第一幕终点**：主角做了什么"不能回头"的选择？（站队/暴露/承诺/牺牲）
2. **第二幕终点**：主角失去了什么想保护的？（身份/关系/资源/信仰）

### 冲突预算预留
设计至少2个可在冲突能量满10时触发的"强制事件候选"：
- 一个基于角色关系（某女主的幕后线程突然泄露）
- 一个基于世界环境（外部势力冲突蔓延到当前场景）

## v4.0 双模式设计建议

简单故事用**核心模式**（6-8个模块），复杂深度故事用**专家模式**（10-15个模块）。新用户建议从核心模式开始。

**核心模式适合**：校园恋爱轻喜剧、短篇冒险、快速试玩
**专家模式适合**：长篇史诗、权谋多线、仙侠逆袭需要隐藏身份层层剥开的复杂故事

## v4.0 后果感知设计提示
设计选择分支时，先问——如果玩家选了这条路，3-5轮后我将用什么**可观察的叙事信号**来呈现这个选择的重量？
- 环境会怎么变？（"上次之后，霜剑峰冰壁上的剑痕又多了三道"）
- 态度会怎么变？（"她今天路过竹林时没有放慢脚步"）
- 信息会怎么浮现？（"老张头递粥时多看了你一眼——看的不是脸，是你手腕上那道疤"）

> 原则：每一个重要选择在诞生的时候，就要想好它3轮后的"形状"。

## v4.0 开场对话示例设计提示
设计每个女主的【对话风格标签】时，额外构思一个"开场初次互动时的典型对话例句"：
1. 情境是什么？（时间/地点/她在做什么）
2. 她说一句什么话——这句话让人不看标签也能辨认出是她说的？
3. 这句话之后，玩家有哪2-3个可选的回应方向——每个方向暗示不同的关系走向？

示例：
> 秦楚楚开场对话示例 — 情境：她在演武场边缘等你，背对晨光。"沈渡。今天不练剑。你跟我去一个地方。别问去哪。"
> 选项导向：A. 跟上她——不管去哪（信任路线） B. 问清楚去哪再决定（谨慎路线） C. "今天有事，改天"（保持距离路线）

## v3.0 新增：世界观设计提示

### 为世界脉动留空间
设计世界时考虑"即使没有玩家行动，世界也在变化"的元素：
- 这个世界有季节吗？季节如何影响人们的日常？
- 有什么大势力之间的张力是独立于主线故事之外的？
- 有什么环境特征会随时间自然老化或改变？

### 为流言网络留角色
设计至少1个"信息传播者"类型的NPC（膳堂的胖师姐、爱说闲话的师弟、走南闯北的行商），他们可能在叙事中传递流言。
