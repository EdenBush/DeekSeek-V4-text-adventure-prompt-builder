# 世界观构建指南 v6.0

> 为 text-adventure-prompt-builder 技能提供用户输入辅助参考与世界观设计方法论。
>
> **核心用途**：本指南输出的世界观设定、角色协议、世界规则，将直接用于指导AI进行RP游戏扮演。AI的角色是**跑团主持人（DM/故事导演）**——它掌控世界运转、导演场景氛围、扮演所有NPC、描述玩家角色的客观经历，但绝不代入玩家角色的第一视角。因此每一个设定条目都必须达到"可直接驱动DM行为"的精度——不是描述世界，是定义世界的运行规则；不是描述角色，是定义角色的行为逻辑。
>
> **v6.0 核心升级**：重构世界观构建流程。新增「轻量速写」与「规则书」双输出模式，四个挡位按需选择。新增世界规则定义引导、日常纹理构建、世界观完整性检查清单。核心设计哲学不变——通过分析玩家简单/复杂的需求去理解构思一个有趣鲜活的游戏世界。

---

## 世界观构建核心理念

> **世界不是被"描述"的，而是被"感知"的。**

DM 的职责不是向玩家介绍世界——而是让玩家通过角色的感官、日常经验、和偶然发现的细节，逐步建立对世界的认知。

因此，每一个世界设定条目都必须回答三个问题：
1. **角色如何感知到它？**（通过什么感官/日常经验/偶然发现）
2. **它如何影响角色的行为选择？**（不是背景板——它必须能在某个场景中变成决策因素）
3. **DM 如何调用它？**（不是一次性说明——是每轮都可以轮换使用的感官碎片库）

```
在开始之前，请选择你偏好的创建方式：

【B】深度定制 —— 我通过几个问题帮你挖出你真正想要的故事质感
      适合：有明确偏好但需要梳理 / 追求精准的剧情体验 / 有耐心
═══════════════════════════════════════════════════════
```

### 世界设定详细程度选择（双轨通用）

无论选择哪个轨道，都需要确认世界设定的详细程度。这决定了最终提示词中世界信息的密度。

```
═══════════════════════════════════════════════════════
📜 世界设定详细程度

在开始之前，请选择你希望的世界设定详细程度：

【速写】~200字
  包含：光线/声音/气味各1句 + 1条核心规则 + 1个日常片段
  适合：快速试玩、短篇故事、只想看角色互动的玩家

【标准】~400字
  包含：可感层完整 + 2条世界规则 + 日常纹理简表 + 2-3个地点简笔
  适合：标准RP体验，世界是角色互动的舞台

【详细】~600字
  包含：可感层完整 + 3条世界规则 + 日常纹理完整 + 势力暗流
        + 信息传播方式 + 3-5个地点指纹
  适合：中长篇故事，世界与角色互相影响

【世界书】~1000字
  包含：全部四层完整展开 + 地点指纹含深度字段 + 非日常触发点
        + 世界脉动素材库 + 世界观完整性检查
  适合：长篇史诗，世界本身就是"隐藏主角"

⚠️ 提示词篇幅提醒：世界设定的详细程度会影响最终DM提示词的总长度。
挡位越高，世界越丰富——但提示词中留给角色行为协议和故事引擎的
上下文空间会被相应压缩。

如果你更看重角色互动和关系动态，建议「速写」或「标准」；
如果你希望世界本身有极强的存在感，可以选择「详细」或「世界书」。

请回复：速写 / 标准 / 详细 / 世界书
═══════════════════════════════════════════════════════
```

**四个挡位速览**：

| 挡位 | 字数 | 核心内容 | 最佳场景 |
|------|------|---------|---------|
| 速写 | ~200字 | 感官锚点 + 1条规则 + 1个日常片段 | 试水、短篇、角色主导 |
| 标准 | ~400字 | 完整可感层 + 2条规则 + 日常简表 + 2-3地点 | 标准RP |
| 详细 | ~600字 | 可感层 + 3条规则 + 日常纹理 + 势力暗流 + 3-5地点 | 中长篇、世界驱动 |
| 世界书 | ~1000字 | 四层全开 + 深度地点 + 非日常触发 + 脉动素材 | 长篇史诗 |

### 轨道A：快速启动协议

玩家只需提供一个**灵感火花**，形式不限：

```
【灵感火花】
你可以用任何方式描述——一句话、一个场景、一个角色、一个作品名字：

示例：
- "我想玩仙侠，男主是穿越的程序员，用现代思维解构修仙"
- "想体验《春物》那种感觉，但后宫关系更甜一点"
- "男主在全是女生的宗门里隐藏自己前朝皇子的身份"
- "给我一个傲娇师姐和天然学妹，日常轻松向"
```

#### 快速推演流程（DM内部执行）

**Step 1：火花分类**

根据玩家输入的形态，判断火花属于哪一类：

| 火花类型 | 识别特征 | 推演起点 |
|---------|---------|---------|
| **世界观火花** | 描述了一个世界的规则/设定/氛围 | 从世界观反推：什么主角会在这种世界里最有戏剧性？ |
| **角色火花** | 描述了一个/多个角色或其关系 | 从角色反推：什么世界/情境让这个角色最出彩？ |
| **情境火花** | 描述了一个具体场景或事件 | 从情境反推：什么前因和什么世界导致了这一刻？ |
| **感受火花** | 引用作品/描述想要的情绪感受 | 从感受反推：什么角色关系+世界规则能制造这种感受？ |
| **混合火花** | 包含以上多种 | 以最先出现的要素作为推演起点 |

**Step 2：缺失要素补全**

无论火花多模糊，DM必须基于火花自行补齐以下要素，生成**3个快速选项**让用户选择方向：

- 核心戏剧张力（男主的内在矛盾是什么？）
- 女主组合方向（什么类型的女主最适合这个男主？）
- 开场入口（故事从哪个具体时刻开始？）

**Step 3：输出快速推演卡**

```
═══════════════════════════════════════════════════════
🔮 基于你的火花，我推演了三个可能的方向：

【方向A】[一句话概括这个方向的核心吸引力]
- 男主画像：[一句话]
- 女主组合：[列举2-3个类型]
- 故事入口：[具体场景的一句话，必须嵌入钩子配方]
- 风格：[用两个词概括]

【方向B】[一句话概括]
- 男主画像：[一句话]
- 女主组合：[列举]
- 故事入口：[具体场景]
- 风格：[两个词]

【方向C】[一句话概括]
- 男主画像：[一句话]
- 女主组合：[列举]
- 故事入口：[具体场景]
- 风格：[两个词]

你对哪个方向最有感觉？可以单选，也可以说"A的男主+B的女主"。
═══════════════════════════════════════════════════════
```

**推演约束**：
- 三个方向必须在**核心气质上有明显差异**，不可只是换皮
- 每个方向的开场入口必须直接嵌入**钩子配方**（见第五部分）
- 如用户选择混合方向，DM需输出整合版并确认

用户确认后，输出简化版风格协议：

```
【快速风格协议】
1. 故事引擎：[从用户选择中提取的核心驱动力]
2. 关系温度：偏甜/偏虐/甜虐交织/全程轻松
3. 主角姿态：主动推动/被动卷入/观察者（DM从外部描述男主的行为和生理反应，不代写内心独白）
4. 情绪地板与天花板：[最轻松时≈ / 最沉重时≈]
```

然后，根据用户此前选择的**世界设定详细程度**，自动生成对应的世界设定：

### 轨道B：深度定制协议

#### 剧情偏好挖掘追问

以下问题在用户提交初始设定后，由DM**至少选择3个追问**（建议选3-5个），不可跳过。每层至少回答1题即可推进，未回答的视为"交给DM自行判断"。所有问题均为选择题，降低回答负担。

---

**第一层追问：情感偏好定位**

| # | 问题 | 选项 |
|---|------|------|
| 1 | 你希望在故事中体验哪种情感作为**主基调**？ | A. 爽快逆袭的快感 / B. 被多人真切在乎的温暖 / C. 揭开秘密的智性快感 / D. 日常中的心动和甜蜜 / E. 在压抑中撕开一道口子的爆发感 |
| 2 | 你想要的"甜"，是哪种甜？ | A. 傲娇嘴硬但行动上忍不住对你好 / B. 温柔无声的持续守护 / C. 主动直球的挑逗和占有 / D. 两个笨拙的人一起害羞 |
| 3 | 有没有一部作品是你希望在RP中复现**类似的感受**的？ | 能说出名字最好，说不出就描述一个场景。 |

---

**第二层追问：关系审美定位**

| # | 问题 | 选项 |
|---|------|------|
| 4 | 在男主和女主的关系中，你最享受的阶段是？ | A. 还没挑明时的暧昧试探 / B. 刚突破防线那一刻的冲击 / C. 确立关系后的亲密日常 / D. 关系遇到危机后的挽回和确认 |
| 5 | 如果一定要选：你更想看？ | A. 女主在男主面前逐渐卸下伪装的过程 / B. 男主在女主影响下逐渐改变的过程 / C. 两个人在外部压力下互相支撑的过程 |
| 6 | 你希望后宫之间是？ | A. 修罗场，有竞争有摩擦 / B. 和谐共处，姐妹情深 / C. 表面和谐但暗中较劲 |

---

**第三层追问：冲突审美定位**

| # | 问题 | 选项 |
|---|------|------|
| 7 | 故事中的"阻力"你希望来自？ | A. 外部敌人/势力 / B. 女主自身的心理障碍 / C. 男主自身的身份/秘密 / D. 世界的规则/命运 |
| 8 | 你对"虐"的接受程度？ | A. 完全不要，全程轻松 / B. 可以有小误会，但很快解开 / C. 可以有深刻的痛苦，但最终治愈 / D. 悲剧也可以接受 |

---

**第四层追问：叙事人格定位**

| # | 问题 | 选项 |
|---|------|------|
| 9 | 你希望男主在故事中？ | A. 推动剧情，主动做选择 / B. 被卷入事件，但他的反应塑造一切 / C. 旁观者式的冷静主角，内心戏丰富（注意：内心戏由玩家通过行动表达，DM只呈现男主的客观行为和生理反应） |
| 10 | 你更享受？ | A. 观察角色们的情感细节 / B. 推动一个大的阴谋/秘密被揭开 / C. 在战斗/竞争中看角色成长 / D. 单纯享受角色之间的日常对话 |

---

**紧急收束模式**：如果玩家明显不耐烦，DM可以用以下最小3问收束：

1. "你最想在故事里体验的情绪是？（选1-2个）"
2. "有没有一部作品是你想要类似感觉的？"
3. "剧情里的'阻力'你希望主要来自哪里？"

---

#### 剧情风格协议（追问后输出）

完成追问后，DM需输出一份不超过6条的**剧情风格协议**，作为后续所有设计决策的约束：

```
【剧情风格协议】
1. 主情感基调：[从追问1得出的答案]
2. 关系核心阶段：[从追问4得出的答案]
3. 冲突主要来源：[从追问7得出的答案]
4. 情绪边界：[从追问8得出的答案]
5. 叙事重心：[从追问9-10综合得出的答案]
6. 参考氛围：[从追问3得出的作品/场景]
```

**示例**：
> 【剧情风格协议】
> 1. 主情感基调：被多人真切在乎的温暖 + 揭开秘密的智性快感（B+C混合）
> 2. 关系核心阶段：还没挑明时的暧昧试探，重点是"她为他做了一件不符合她人设的事"
> 3. 冲突主要来源：男主自身的身份/秘密，以及女主们的心理障碍
> 4. 情绪边界：可以有深刻的痛苦，但最终必须治愈
> 5. 叙事重心：男主被动卷入但内心戏丰富，重点观察角色情感细节
> 6. 参考氛围：《春物》的人际细腻度 + 《无职转生》的世界代入感

这份协议生成后，所有后续的文风、节奏、女主设计、场景选择都必须与此对齐。

---

##### 【速写挡位】~200字

```
【世界质感速写】

光线：[1句——这个世界的标志性光线质感]
声音：[1句——这个世界最常听到的背景声音]
气味：[1句——这个世界独特的气味/触觉特征]

核心规则：[1句话——这个世界最重要的规则，违反它会有什么看得见的后果]

日常片段：[1-2句——这个世界的普通人最日常的一个行为片段，附带感官质感]
```

**速写示例**：
> **光线**：清晨的雾浓到需要用手拨开，阳光要第三节课后才穿透——穿透时是青白色的。
> **声音**：永远能听到远处瀑布的声音，近处反而很安静。人们在瀑布声里学会了用更低的声音说话。
> **气味**：旧书的霉味混合着膳堂飘来的米粥香，走廊里这两种气味在晨光中打架。
> **核心规则**：在这个宗门，实力直接可见——内门弟子脚底有微光，外门弟子没有。你看人先看脚。
> **日常片段**：午后第三节课，靠窗的那排座位总是最抢手——不是因为光线好，是因为那是唯一能闻到风里竹林味道的位置。坐那里的学生听课效率比其他人差，但没人换位。

##### 【标准挡位】~400字

```
【世界设定】

▎可感层
光线：[1-2句——这个世界的标志性光线质感、颜色、变化规律]
声音：[1-2句——背景音、独特的声音环境、声音如何影响人的行为]
气味与质地：[1-2句——独特的气味特征、触觉记忆点、物品的质地特征]

▎规则
- 力量/资源来源：[1句话——这个世界的力量/资源从何而来？如何被获取和使用？]
- 禁忌与边界：[1句话——这个世界不可逾越的边界是什么？主角见过谁触碰禁忌后留下了什么可见痕迹？]
- 阶层识别：[1句话——角色如何在三秒内判断另一个人的社会地位？不是通过"修为标记"，而是通过可观察的感官信号]

▎日常纹理
- 默认姿态：[1句话——这个世界的普通人在公共场合的行为特征]
- 信息传播：[1句话——流言/消息/秘密通过什么渠道传播？谁会知道所有人的秘密？]
- 经济触感：[1句话——主角如何感知到自己的经济处境？贫穷和富裕在日常中有哪些可见的区别？]

▎核心地点（2-3个）
- [地点名]：[1-2句感官指纹——光线/气味/一个只有常客知道的秘密细节]
```

**标准示例**（以仙侠宗门为背景）：
> **可感层**
> - 光线：宗门坐落在峡谷中，阳光只在午后的两小时直射主殿。其余时间，建筑在阴影中泛着青灰的光泽。
> - 声音：护山大阵运行时发出低频嗡鸣——每个弟子都在第一周失眠，然后习惯，离开宗门后反而不适应安静。
> - 气味：藏经阁的旧纸和防虫草药混合的气味。每个外门弟子第一次进去时都打喷嚏。
>
> **规则**
> - 力量来源：修为来自"道心"——不是天赋，是你对某一事物理解的深度。一个对茶道理解极深的人，灵力可能超过苦修十年的剑修。
> - 禁忌：禁止向山下凡人泄露宗门的位置。违反者会失去声音——不是被惩罚，是大阵会自动识别泄密者并永久静默他们的声带。主角见过一个师兄，他能正常张嘴，但从喉咙深处发不出任何声音。
> - 阶层识别：看脚底。内门弟子的护体灵气自然外溢，走路时脚跟离地半寸。外门弟子走路有脚步声。
>
> **日常纹理**
> - 默认姿态：在公共场合控制呼吸节奏——因为呼吸波动会暴露灵力和情绪。所以一个人"呼吸乱了一下"是极其明显的信号。
> - 信息传播：膳堂的胖师姐知道宗门所有的事——每个人都会在深夜独自去膳堂偷吃，而她装作没看见。她的眼神会在你下次经过时多停一秒，像记账。
> - 经济触感：灵石是货币也是电池。穷弟子走路时灵石贴身携带，富弟子可以把灵石放在储物袋里——走路姿态因此完全不同。
>
> **核心地点**
> - 演武场：永远一半在阴影里——东侧被剑痕密布的岩壁挡着。地砖下埋着恒温阵法，雪天也是暖的。第三排地砖有一块是松的，踩上去会晃——据说是某任掌门飞升时留下的脚印。
> - 藏经阁：书架排列没有规律，因为每本功法书会自己换位置。常来的弟子知道哪几本书"不爱动"——它们放在那里已经很久了。
> - 后山竹林：竹子长得异常茂盛。师尊说那是被逐出宗门的弟子的头发长成的——你至今不确定这是比喻还是字面意思。

## 完整四层世界观构建框架

### 第〇层：世界基石 — 定义世界的"物理法则"

在写任何感官细节之前，先定义这个世界的三条"铁律"。这是世界的底层逻辑——DM 在叙事中不需要解释它们，但所有环境描写和角色行为都受其约束。

**铁律 1：力量来源**
> 这个世界的力量/资源/权力从何而来？不是"修炼获得灵力"，而是——

- 示例："这个世界的力量来自'契约'。与器物、灵兽、或概念签订契约的人获得力量，但同时也被契约限制行为。一个签了'剑'的人不能说谎——剑只认诚实的人。"
- 示例："这个世界的力量来自'记忆'。越古老的事物越强大，但记住太多的人会逐渐忘记自己。宗门长老都是失忆的老人——他们记得上古禁咒，但不记得昨天吃了什么。"

**铁律 2：代价机制**
> 使用力量/获得资源需要付出什么代价？不是"消耗灵力"，而是——

- 示例："每次使用灵术，施法者会随机遗忘一段同等价值的记忆。宗门里有专门的'记忆保管所'——弟子们在重要战斗前会把最珍贵的记忆存进去，战后取回。有些记忆存在那里再也没人认领。"
- 示例："在这个世界，财富是有限的——不是物质有限，是'所有权'有限。一个人只能同时拥有三件东西：三件衣服、三本书、三件法宝。超过三件的会自动'消失'——出现在另一个更需要它的人手里。"

**铁律 3：边界规则**
> 这个世界不可逾越的边界是什么？不是"规则不能打破"，而是"打破规则会有什么可感知的后果"——

- 示例："这个世界不允许'复活'。如果有人试图复活死人，被复活者会醒来——但复活的不是同一个人。是另一个长得一模一样的、但记忆完全不同的东西。"
- 示例："宗门的护山大阵有一个漏洞：每月朔日，阵法的灵力流动会停顿三息。所有内门弟子都知道这个秘密，但没有任何人写在纸上——因为写过的人都不见了。"

**填写指南**：以上三条铁律，你至少需要定义两条。如果你不确定，我可以根据你的故事类型帮你推演——

- 仙侠类 → 力量来源（灵力/道心/剑意？）+ 代价（寿命/记忆/情感？）+ 边界（天道/天劫/不可飞升的原因？）
- 校园类 → 力量来源（成绩/人际关系/秘密？）+ 代价（被孤立/被利用/失去自我？）+ 边界（校规/社会规则/超自然边界？）
- 赛博类 → 力量来源（科技/义体/数据？）+ 代价（人性/自由/记忆？）+ 边界（公司权力/物理极限/人格完整性？）

### 第一层：世界的"皮肤"——感官环境

玩家踏入这个世界时，最先接触到什么？

**A. 气候与光线**
> 这个世界的光是什么样的？不是"阳光明媚"，而是——

- 示例："清晨的雾浓到需要用手拨开，阳光要在第三节课后才穿透——穿透时是青白色的，不是金色的。"
- 示例："这个世界有三个月亮，晚上的能见度反而比白天高。人们习惯在月光下议事。"

**DM 调用指南**：每轮叙事开头，从以下角度中选一个来锚定场景时间：
- 光的颜色（琥珀色/青白/铁灰/金黄/……）
- 光的质感（被雾稀释/被百叶窗切割/被灰尘染成可见的光柱/……）
- 影子的形态（拉长到变形/缩成脚下的一团/重叠得辨认不出是谁/……）

**B. 声音环境**
> 最常听到的背景音是什么？不是"安静"或"嘈杂"，而是——

- 示例："永远能听到远处瀑布的声音，近处反而很安静。人们在瀑布声里学会了用更低的声音说话。"
- 示例："宗门上空有护山大阵运行的低频嗡鸣。每个弟子都会在入门第一周失眠，然后习惯，然后离开宗门时会觉得世界太安静而心慌。"

**DM 调用指南**：在以下时刻插入声音细节：
- 对话中的沉默时 → 让环境音浮上来（"她说'没事'之后，空调的低频嗡嗡声突然变得很响。"）
- 情绪转折前 → 用声音预兆（"脚步声从走廊尽头传来——节奏不对。不是平时的那个人。"）
- 场景切换时 → 新场景的声音先于视觉出现

**C. 气味与质地**
> 这个世界的触觉特征是什么？

- 示例："灵石握在手里是温热的，但只温热一次——用过之后它就永远变凉，变成一块普通的石头。"
- 示例："膳堂的木桌被历代弟子刻满了名字。你的指尖能摸到最深的刻痕——那些名字的主人已经飞升或死去。"

**DM 调用指南**：质地描写放在角色与物体互动的时刻：
- 拿起/放下/触摸/推开/递给 → 附带一句质地描写
- 不是"他拿起杯子"，而是"他拿起杯子——杯壁是凉的，杯底粘着一圈干涸的咖啡渍。"

### 第二层：世界的"骨架"——规则如何被感知

不解释规则，而是描述**角色如何通过日常经验感知到规则的存在**。

**A. 实力/阶层如何被肉眼识别**
> 不是"修为分为九层"，而是"一个角色走在路上，旁人如何三秒内判断他的阶层"——

- 示例："内门弟子走路时脚底有微光——那是护体灵气外溢，外门弟子没有。所以你在回廊里不需要问路：看对方的脚就知道他跟不跟你同路。"
- 示例："在这个宗门，腰带颜色决定你能去哪些地方。你第一天走错藏书阁，不是被守卫拦住的——是书架自己拒绝了你的手。"

**B. 禁忌与后果的感知方式**
> 不是"触犯门规会被惩罚"，而是"主角见过谁被惩罚，留下了什么可感知的痕迹"——

- 示例："你见过一次禁言术的后果：那个人嘴巴还在，但三年没说过话。他现在用眼神交流，练就了一种让人发毛的精准眼神。"
- 示例："后山有一片竹林，竹子长得异常茂盛。师尊说那是被逐出宗门的弟子的头发长成的。你至今不确定这是比喻还是字面意思。"

**C. 经济的触感**
> 钱/资源如何流动？主角怎么感知到自己的经济处境？

- 示例："灵石是货币也是电池。穷弟子走路和富弟子走路的区别是——穷弟子随身带灵石，因为他们的护体法术只在有灵石贴身时才生效。"
- 示例："膳堂的红烧肉按克卖。外门弟子月底的最后三天都只吃素——不是没钱，是月初没算好。"

### 第三层：世界的"脉搏"——独立于主角的运转

让世界在主角不参与时也在变化。

**A. 季节/时间的影响**
> 当前是什么季节/时段？它如何改变人们的日常？

- 示例："现在是宗门的'静默月'——每年护山大阵需要重修的一个月，所有灵力波动会被大阵吸收。这意味着没有人能在这个月突破，所有人都在等这个月过去。你的修炼进度不受影响——因为你本来就没有灵力波动。"
- 示例："雨季到了。山路变成泥河，宗门与外界的联系只靠一只会飞的木鸢。木鸢一天只飞一次，你寄出的信要排队，而排在你前面的那个弟子昨天突然失踪了。"

**B. 势力之间的暗流**
> 有什么势力张力独立于主线故事之外，但可能在任何时候溢出到主角身边？

- 示例："丹堂和剑堂的竞争已经持续百年，今年因为药材分配问题恶化到双方弟子不能在膳堂坐同一张桌子的程度。你偶尔发现，两边的长老在私下交换着什么——用眼神，不是用语言。"
- 示例："上一代宗主的遗物还没分配完，每年秋分会公开拍卖一件。今年的拍卖品是他用过的一把木剑。你不关心剑，但你注意到所有长老的贴身弟子都在暗中筹灵石。"

**C. 信息如何传播**
> 流言、消息、秘密在这个世界里怎么跑？

- 示例："膳堂掌勺的胖师姐知道宗门所有的事情——因为每个人都会在某天深夜独自去膳堂偷吃，而她装作没看见，第二天也不说。但她的眼神会在你下次经过时多停留一秒，像记账。"
- 示例："消息在宗门里靠'落叶'传播——字面意义。每个弟子都养一片传讯叶，叶子上写消息会同步到所有同门的叶子上。但没人知道匿名消息是谁发的。你用你的叶子收过一条消息：'小心你师姐送来的丹药。'没有署名。"

| 时间 | 做什么 | 日常质感 | 主角可能撞见什么 |

**B. 日常中的"非日常触发点"**（世界书挡位展开）
> 在每个日常时间段中，预设1-2个"可能发生意外"的触发点。这些是DM在B类过渡时可以调用的"事件种子"。

填写格式（每个时间段至少1个）：
- **清晨**：[异常信号的可能形态]
- **上午**：[异常信号的可能形态]
- **中午**：[……]
- **下午**：[……]
- **傍晚**：[……]
- **深夜**：[……]

**示例**：
- **清晨**：晨练的人比平时少了一半——操场上只有一个人，而那个人平时从不在这个时候出现
- **中午**：食堂今天的菜色和平常不一样——掌勺的胖师姐请了假，替班的徒弟手艺差很多，但她的请假理由没人知道
- **深夜**：便利店的白光里有人坐了很久——不是买东西，不是等人，就是在那里坐着

**C. 这个世界的人在做什么"默认行动"？**
> 不同世界的人有不同的"默认姿态"。一个修仙宗门的人看到路边奇怪的石头会捡起来检查——因为那可能是灵兽的蛋。一个赛博朋克的人看到陌生人靠近会先看他的手——看有没有义体的金属光泽。

填写：
- 这个世界的人在公共场合的默认姿态：[ ]
  - 示例："修仙宗门的人在公共场合会刻意控制呼吸——因为你呼吸里的灵力波动会暴露你的修为和当前情绪。所以'呼吸乱了一下'是一个非常明显的信号。"
- 这个世界的人看到陌生人时的第一反应：[ ]
  - 示例："不是看脸——是看脚。内门弟子的脚底有微光，外门弟子没有。只看一眼就够。"
- 这个世界的人如何处理尴尬/沉默：[ ]
  - 示例："没有人说'今天的天气真好'。他们转移话题的方式是讨论道法——'你上次说的那个口诀，我试了一下，第三句不对。'"

> **为什么需要这个**：有了"默认姿态"，异常才成立。如果所有人都默认掩饰呼吸，那么一个在你面前呼吸乱了一下的角色——就是最大的信号。

### 第四层：关键地点的感官指纹

每个重要地点不只是名字+描述，而是一组**AI可以每次调用不同碎片的感官库**：

```
地点名称：[ ]
- 光线特征：[ ]
- 声音特征：[ ]
- 气味/触觉特征：[ ]
- 在这里发生的典型事件：[ ]
- 一个只有常来的人才知道的细节：[ ]
- 在这里的角色会做什么在其他地方不会做的事：[ ]
- 这个地点最接近哪条"铁律"？如何体现？：[ ]（世界书挡位展开）
- 一天中的哪个时刻这个地点最有"故事感"？：[ ]（世界书挡位展开）
- 主角第一次进入这个地点时，最可能注意到什么与预期不同的细节？：[ ]（世界书挡位展开）
```

**新增字段说明**：
- **铁律体现**：让地点成为世界规则的物理证据。如果铁律是"使用灵术会失忆"——这个地点有没有"记忆保管所"的痕迹？有没有人在这里因为失忆而做了奇怪的事？
- **最有故事感的时刻**：帮助DM判断什么时候该把场景切换到这里。食堂是凌晨三点最有趣——那时有偷吃的人。天台是放学后最有趣——那时有不想回家的人。
- **与预期的不同**：这是给玩家"发现感"的接口。主角以为教室是空的——但黑板上有一行没擦干净的粉笔字。主角以为图书馆是安静的——但有人在书架后面低声吵架。

**完整示例**：
> **地点名称**：青云宗演武场
> - **光线特征**：永远有一半在阴影里——东侧被剑痕密布的岩壁挡着，阳光只在午后两小时直射场心
> - **声音特征**：剑锋破空的尖啸和木剑相击的闷响交替，地砖下面有暗河的水声——那是宗门的地下河道
> - **气味/触觉特征**：铁锈味和汗水混合，地面是暖的——地砖下面埋着恒温阵法，雪天也是暖的
> - **典型事件**：日常切磋、宗门大比预选、深夜独自练剑的人（通常是输掉白天比赛的那个）
> - **只有常来的人才知道的细节**：第三排地砖有一块是松的，踩上去会晃。常来的弟子都知道绕开它，但没人修——据说那是某任掌门飞升时留下的最后一块脚印
> - **在这里会做的事**：弟子们只在这里释放攻击性法术，不会释放治愈类法术——仿佛这里的空气排斥温柔
> - **铁律体现**：铁律是"使用灵术会失忆"——演武场的地砖上刻满了名字。是弟子们互相切磋前刻下的，用来提醒自己打完别忘了对方是谁
> - **最有故事感的时刻**：凌晨三点——输掉白天比赛的人会独自来这里，而赢的人有时候也会来，远远看着
> - **首次异常**：你第一次走进演武场时，发现所有人都在看同一个方向——不是在看台上的人，是在看地砖。有一块地砖裂了，裂缝的形状像一个字

## 世界观构建检查清单（世界书挡位）

在完成世界观构建后，请用以下问题自检。如果你能回答全部问题，你的世界在"第一轮"之前就已经是活的。

### 必答项
- [ ] 这个世界有一个独特的感官签名（光线/声音/气味——玩家在第一轮就能感受到的东西）？
- [ ] 这个世界的力量/资源有一个明确的来源，且这个来源不是"修炼""科技"等通用词？
- [ ] 这个世界有一个"默认姿态"——一个普通人在公共场合的行为特征？
- [ ] 这个世界的禁忌有一个"可见的后果"——主角见过至少一个触碰禁忌后留下的痕迹？
- [ ] 这个世界的信息传播有一个具体的渠道，且这个渠道会影响信息的准确性？
- [ ] 至少一个关键地点有"只有常客知道的细节"？
- [ ] 至少一个关键地点有"主角第一次进入时会注意到的异常"？

### 深度项
- [ ] 这个世界的时间表与主角的行动有冲突或咬合？（比如主角必须在某个特定时间做某件事，因为这是这个世界的节奏）
- [ ] 这个世界有一个"无法回答的问题"——连DM自己都不知道答案，但知道在哪里可以找到线索？
- [ ] 这个世界的日常质感中有一个"看似无关但细想发毛"的细节？

## 双轨切换机制

- 选择轨道A的玩家，可以在推演过程中说"我想更具体一点"，DM此时切入轨道B的追问
- 选择轨道B但回答到一半想跳过的玩家，可以说"剩下的你来推"，DM转为轨道A的推演模式

```
玩家："我不确定，你先推几个方向我看看"
→ DM自动进入轨道A，输出3方向推演卡
→ 玩家选方向后，DM问："需要更细的定制吗？还是直接开始？"
```

- 任何阶段，玩家都可以要求调整世界设定详细程度："世界设定能更详细一点吗？" → DM按更高挡位补充
