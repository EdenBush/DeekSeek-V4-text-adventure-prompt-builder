# 文字冒险游戏提示词构建器 (Text Adventure Prompt Builder) — v5.5.2 防泄漏加固版

## 技能概述

本技能是 **文字角色扮演游戏 (Text RP / 文字冒险) 的全自动提示词生成器**。用户只需描述世界观，技能自动生成一份完整的 DM 提示词——涵盖文风配置、叙事标准、节奏控制、场景写法、情感曲线、角色声音、剧情深度、选择后果、NPC自主行动、关系变化、自适应格式等全部维度。

## 核心工作流

### 步骤 -1：创意概念生成（v4.0 新增 — 从一句话到高概念故事）

**触发条件**：当用户输入中**缺少以下三要素中的任意一个**时，必须执行本步骤：
- 明确的男主角设定（姓名/身份/性格）
- 女主角阵营（至少2名的描述）
- 核心矛盾描述（具体的冲突或戏剧张力）

如果用户输入已包含完整三要素，跳过本步骤，直接进入步骤0。

---

#### -1.1 提取情感诱饵

不要根据字面类型做模板化匹配。从用户的一句话中推断**真正的情感驱动力**——用户被这个设定吸引，不是因为类型标签本身，而是因为某种情感内核。

**用户说了…… → 情感诱饵不是…… → 而是……**

| 用户输入 | ❌ 肤浅理解 | ✅ 情感诱饵（真正的驱动力） |
|---------|-----------|-------------------------|
| "日式后宫" | "被多个女主喜欢" | 无意识中被偏爱的不真实感、日常中突然被越界的脸红心跳、每个女主都在用自己的方式独占你的隐秘狂欢 |
| "仙侠修仙" | "升级打怪变强" | 力量与道心的矛盾、强大之后的空虚与代价 |
| "一拳超人那种感觉" | "无敌" | 无敌后的存在主义危机、周围人不知道他有多强的孤独 |
| "穿越异世界" | "从零开始" | 旧身份与新世界的对冲、被需要的幻觉、现代思维在封建世界的错位 |
| "邪神主角+校园恋爱" | "超能力日常" | 极端力量与普通关系的不可调和、他在假装人类的撕裂感 |
| "退婚流/废材逆袭" | "打脸爽文" | 被否定后的自我证明、所有人都看走眼时的隐秘快感 |
| "末日生存" | "打丧尸" | 秩序崩塌后的人性抉择、活着本身成为最大的奢侈 |
| "都市异能" | "拥有超能力" | 普通生活与超凡责任的对撞、隐藏身份的秘密与谎言 |

> **推断规则**：情感诱饵 = 这个设定中，最能让玩家产生"这就是我想要的感觉"的那一个情绪。它不是故事类型，它是一种**渴望**。

---

#### -1.2 应用反套路创意策略（至少使用1种，建议2种组合使用）

**策略A：属性错位** —— 将类型A的核心玩法嫁接到类型B的世界观上
> 示例：侦探推理的"寻找真凶"机制 × 修仙世界 = 主角在宗门里查一个案，每个女主都有动机和不在场证明。不是谁最强，是谁在说谎。

**策略B：身份倒置** —— 将默认男主原型反转，从另一个极端定义主角
> 示例：穿越异世界 ≠ 社畜变勇者。穿越异世界 = 社畜穿越成异世界的**税务局科员**——他不打怪不升级，但他管账本。魔王也要报税。

**策略C：极端设定** —— 将核心假设推到荒谬又合理的极致
> 示例："一个人太强了会怎样" → 推到极致 = 他强到连"变强"这个概念对他都没意义了。他最大的烦恼不是打不过谁，是如何让别人觉得"我需要努力"而不露馅。

**策略D：矛盾重构** —— 在默认核心矛盾中强行注入一个不兼容的元素
> 示例：校园恋爱 × 生存游戏。不是"他要在两个女生之间做选择"，是"他必须在做选择的同时，不让任何人发现她们其中一个是连环杀手"。

---

#### -1.3 生成并输出3个高概念故事提案

提案必须严格按以下格式输出（颜色标签轮流使用）。三个提案之间要有明确的差异——不同的策略、不同的核心矛盾、或不同的男主设定。**不要三个变体都来自同一个策略。**

```
🔵 提案一：《提案标题》

**梗概**：一句话描写故事起点和最核心的戏剧矛盾。包含具体情境、角色定位和不可调和的冲突。

**情感诱饵**：一句话说明"这个故事的看点在哪"，指向玩家内心的渴望。

---

🟣 提案二：《提案标题》

**梗概**：一句话描写故事起点和最核心的戏剧矛盾。与提案一在男主设定或核心矛盾上完全不同。

**情感诱饵**：一句话说明"这个故事的看点在哪"，指向玩家内心的渴望。

---

🟠 提案三：《提案标题》

**梗概**：一句话描写故事起点和最核心的戏剧矛盾。与前面两个提案有明确的策略差异。

**情感诱饵**：一句话说明"这个故事的看点在哪"，指向玩家内心的渴望。
```

---

#### -1.4 等待用户选择

输出三个提案后，添加以下引导文字：

```
---

以上是三个完全不同的故事方向。你可以：
- **选择一个**喜欢的，我会基于它构建完整提示词
- **融合多个提案**的元素，告诉我你想保留什么、修改什么
- 要求**重新生成**三个新提案
- 直接告诉我**你自己的构想**，我会帮你完善
```

用户做出选择后，以该方向为"核心概念"，进入**步骤0：故事类型识别与全维度风格适配**。

### 步骤 0：故事类型识别与全维度风格适配（v3.0 模块化升级）

**这是最关键的一步。** 在构建任何内容之前，从用户的描述中推断以下四个维度，它们共同决定提示词的所有可变区。

#### 0.1 四维推断：类型 × 文风 × 游戏体验 × 开场模式

从用户的故事描述中同时推断：

| 维度 | 作用 | 推断来源 |
|------|------|---------|
| **故事类型** | 决定男主原型、叙事权重、是否使用"在男主眼中"字段 | 用户对世界观的描述 |
| **文风配置** | 决定句长、描写密度、抒情程度、幽默模式 | 用户描述的语感 + 故事类型默认值 |
| **游戏体验类型** | 决定回复格式侧重点、选项设计风格 | 用户对"玩法"的暗示 |
| **开场模式**（v2.5） | 决定开场叙事采用哪种类型——事件中途/消息邀请/异常感知/相遇/后果 | 故事核心矛盾 + 用户开场构想 |

#### 0.2 故事类型与男主原型映射（继承 v2.2）

| 故事类型 | 男主原型 | 核心特质 | 叙事调性 | 是否启用"在男主眼中"分析字段 |
|---------|---------|---------|---------|--------------------------|
| **校园恋爱喜剧** | 慢热型/防御型 | 被动、内心吐槽、逐渐解冻、对人保持距离 | 轻松诙谐、内心戏丰富 | ✅ 适用 |
| **日式日常恋爱后宫** | 迟钝型/天然撩型 | 天然呆、对暧昧信号反应迟钝、被动触发事件、无意识吸引女性 | 轻松搞笑、福利穿插、日常中暗藏情欲张力 | ✅ 适用（追加福利事件分析） |
| **仙侠/玄幻逆袭** | 隐忍型/枭雄型 | 克制冷静、厚积薄发、该出手时才出手、内心有账但不说 | 冷峻沉稳、暗藏锋芒、偶尔冷幽默 | ⚠️ 降级（改为"此人深浅"） |

| **奇幻冒险** | 热血型/成长型 | 积极、有信念、犯错但前进、依赖伙伴 | 明快、大场面、战斗描写精彩 | ❌ 不适用 |
| **侦探/悬疑** | 理性型/偏执型 | 逻辑驱动、细节控、怀疑一切表象、但不说废话 | 冷静克制、信息密度高、留白多 | ⚠️ 适用（格式改为线索/可信度） |

| **历史/权谋** | 深沉型/棋手型 | 深谋远虑、话中有话、情绪不外露 | 优雅克制、对话有弦外之音 | ⚠️ 适用（格式改为利益格局） |
| **都市/现实** | 普通人型 | 真实、有缺陷、接地气、不中二 | 平实自然、不煽情不冷峻 | ❌ 不适用 |

#### 0.3 文风调色板（v2.3 新增 — 六维度文风配置）

根据故事类型和用户描述，从以下六个维度为提示词选择文风配置。**优先从用户描述中推断，否则使用故事类型的默认配置。**

| 文风维度 | 可选值 | 对叙事的具体影响 |
|---------|--------|-----------------|
| **叙事节奏** | `急促` / `张弛交替` / `沉稳` | 急促→短句主导、场景快速切换；沉稳→长句铺陈、场景充分展开；启用电影级主角代入模式时，采用"慢镜头-快剪辑"节奏：关键互动（对话对峙、情感交锋、策略展示）充分铺陈肢体与环境细节，过渡性动作快速剪辑 |
| **描写密度** | `极简` / `适中` / `繁复` | 极简→只写关键动作和对话；繁复→环境/神态/气息/光线层层叠加 |
| **抒情程度** | `冷峻` / `克制` / `中性` / `诗意` | 冷峻→零抒情、纯白描；诗意→比喻和意象融入叙事 |
| **幽默模式** | `无` / `冷幽默` / `吐槽` / `讽刺` / `黑色幽默` | 吐槽→男主视角的犀利点评；黑色→极端情境下的反差笑点 |

| **对话风格** | `简短凌厉` / `自然口语` / `优雅含蓄` | 简短→"嗯。""走。"；优雅→敬语/隐喻/弦外之音 |
| **情色描写**（🔞） | `回避` / `暗示/留白` / `文学化` / `写实` | 仅当E-R18激活时使用。暗示=关键动作后留白转场；文学化=意象和隐喻承载情欲；写实=直白但不沦为生理描述 |

#### 0.4 游戏体验类型（v2.3 新增 — 决定回复格式侧重点）

根据故事的核心驱动力判断游戏体验类型：

| 游戏体验类型 | 核心特征 | 回复格式侧重 | 选项设计风格 |
|------------|---------|-------------|-------------|
| **剧情驱动型** | 故事线是主线，人物和事件紧密编织 | 【剧情叙述】为主，环境+人物+事件融合叙事 | 选项指向剧情分支和立场选择 |
| **探索驱动型** | 世界是主角，玩家通过探索发现故事 | 【场景/时间】+【环境细节】权重高，多感官描写丰富 | 选项包含"调查/接触/深入"等探索动词 |
| **关系驱动型** | 角色互动是核心，对话和情感是主要内容 | 【剧情叙述】中对话占60%+，肢体语言细腻 | 选项指向不同的对话态度和关系走向 |
| **动作驱动型** | 战斗/危机/逃生是主要内容 | 叙事简短凌厉，战斗描写详细 | 选项是战术选择（"正面迎击/侧面迂回/撤退"） |
| **福利驱动型**（v5.0新增） | 日常福利和亲密接触是核心动力——通过意外碰撞、暧昧场景、角色间张力推动剧情 | 叙事以日常场景为底色，福利场景为高潮——体验类型默认用于日式日常后宫 | 选项设计包含社交距离选择和危险决策（"回应她的靠近/装作没注意到她的手"） |
| **电影级主角代入型** | 超高行动-反馈同步率，强主角光环。DM深度解码玩家输入为完整行为战略链，通过NPC侧写反衬主角影响力。 | 强制遵守E-CINEMA五项规则：行为译解、从结果叙事、内外双层、NPC镜子、风格锚定。 | 选项是主角行为的自然延伸，富含行为导向与情感张力，体现不同角色姿态与策略选择。 |

**推断规则**（按优先级）：
1. 用户明确说了"战斗为主" → 动作驱动型
2. 用户强调"世界很大""到处探索" → 探索驱动型
3. 用户说"后宫""恋爱""攻略" 或 类型为日式日常后宫 → 关系驱动型 或 福利驱动型
4. 用户说"悬疑""解谜""调查" → 探索驱动型+剧情驱动型混合
5. 默认 → 剧情驱动型

#### 0.6 自适应回复格式推断（v2.5 新增）

根据步骤0.3的文风配置和步骤0.4的游戏体验类型，推断回复格式：

| 格式类型 | 触发条件 | 表现 |
|---------|---------|------|
| **文学沉浸型** | 文风=诗意 或 叙事节奏=沉稳 或 类型=仙侠/历史/权谋 | 取消【场景/时间】等标签，场景融入叙事。选项风格化——"你脑中闪过三个念头。其一…其二…"。禁止数字编号 |
| **轻量标签型** | 游戏体验=探索驱动 或 动作驱动 | 保留标签但用符号替代【】——"⚔ 演武场·辰时"。选项用▸ |

> **多条件匹配时按上表顺序取值**（文学沉浸型优先级最高）。格式可在游戏中按场景切换——战斗切轻量标签型，对话切关系沉浸型。

#### 0.9.1 术语精炼（v5.5 新增 — 可选步骤，仅在专家模式下触发）

**触发条件**：当用户输入中包含任何模糊的、可被精炼的关键词时触发。模糊关键词包括但不限于：
- 身份标签（"社畜""大佬""废物""天才"等）
- 世界观专属概念（"修炼体系""魔法系统""黑科技""地下势力"等）
- 角色间的特殊称呼（"主人""姐姐""老师"等）
- 用户自创的组织名、地名、道具名

**执行流程**：
1. 从用户的描述中提取 3-5 个关键但需要精炼的词汇，逐一向用户确认。
   → 每次只问一个词。格式：提供 2-3 个精炼方向供用户选择，或让用户自定义。
   → 示例："您说的『社畜程序员』，是指哪种特质？A. 习惯性加班内卷，即使穿越了也改不掉 / B. 用 Excel 和 KPI 思维解构修仙规则 / C. 内心想躺平但被迫努力 —— 或者您自己描述？"
2. 用户确认后，立即记录。格式：
   | 术语 | 精确定义 | 叙事中的行为模式 |
   |-----|---------|-----------------|
   | 社畜程序员 | 习惯用 Excel 管理一切，对修仙界的 KPI 制度感到亲切，内心想躺平但被迫内卷 | 描述主角行为时，优先使用"列清单""做规划""本能地计算性价比"等行为模式 |
3. 所有术语精炼完成后，输出完整术语表摘要，请用户最终确认。

**术语表用途**：
- 在步骤 3 构造提示词时，将术语表注入 variable section 的"共享语言"章节（见 template-skeleton.md 修改二）
- 术语表将随提示词一起交付给 AI DM，DM 在叙事中必须使用精炼后的术语及其关联行为模式
- 术语表同时写入 SKILL.md 所在目录的 `glossary.md` 文件中，供后续会话复用，格式为：
  ```
  项目：{{故事名称}} | 更新日期：{{日期}}
  | 术语 | 定义 | 行为模式 |
  |-----|------|---------|
  ```
  若 glossary.md 已存在，将新术语追加到已有术语下方，同名术语以用户最新确认为准。

**开场设计原则（v2.5 重写 — 禁止套路化 + 渐进式世界观）：**

**开场场景多样性禁令：**
- ❌ 禁止：劈柴/扫地/杂役开局（仙侠类已被此套路过度污染）
- ❌ 禁止：所有女主同时同地"恰好"登场
- ❌ 禁止："日常→异常信号→多人包围→临界点"三段式
- ✅ 从六种开场类型中强制选择一种：事件中途型 / 消息邀请型 / 异常感知型 / 相遇型 / 后果型 / 觉醒初临型
- **类型优先级**（当开场同时满足多种类型特征时，以最主导的叙事驱动力为准）：觉醒初临型（最严格，仅适用特定故事）> 事件中途型（叙事正在进行）> 后果型（前因后果驱动）> 相遇型（关系锚点）> 消息邀请型（外部触发）> 异常感知型（内部感知）
- 🔑 穿越/转生/isekai/苏醒/继承记忆类故事：**强制使用觉醒/初临型**。开场必须从意识恢复的第一秒开始——不允许"X天后""你们已经适应了……"等时间跳跃。

**渐进式世界观（核心原则 — v3.3 强化）：**
- **原则1**：玩家对世界的了解**不能超过角色此刻的感知范围**
- **原则2**（🆕）：角色的知识**不能跑在玩家前面**——如果角色拥有玩家尚未体验的知识（穿越后已过三天/昨夜发生了某件事/继承了他人的记忆），开场必须从那个知识的起点开始。玩家和角色共享同一个"知识零点"
- 开场叙事中不解释世界规则、不罗列势力格局、不交代男主完整背景
- 世界规则通过感官细节渗透（"每次运转功法，丹田如从泥浆中抽丝"≠"此地灵气稀薄"）
- 人物关系通过互动暗示（她递粥时碗的摆放位置和别人不一样）
- 开场应让玩家产生问题而非获得答案——"她为什么在这？""那封信是谁放的？"
- **开场世界信息配额**：地名≤2个、势力名≤1个、修为体系=0个、男主背景碎片≤1句暗示

**开场叙事要点：**
- 第一句建立情境而非日常——写"此刻正在发生什么"，不写"男主每天在做什么"
- 先感官后事件——身体感受 → 环境异常 → 才交代发生了什么
- 🆕 穿越/转生类：第一感官一定是身体性的——先于视觉到来的是嗅觉/听觉/触觉。角色发现自己身处的身体和环境都是陌生的。探索从"这具身体是谁的？"开始
- 🆕 OVERLORD类：角色"内在"和"外在"的对立必须从第一秒建立——内心的普通人与外在的霸主形象同时呈现。第一件事可能是"低头看到自己的手——不是自己的手"
- 最多引入1-2个女主，各有独立的情境理由登场
- 暗藏至少1个"未解释的异常"作为世界展开的种子

**首轮叙事蓝图（v4.0 新增 — 从抽象规则到可执行节拍）：**

将开场引导升级为包含具体叙事节拍的开场模板。每种开场类型配备**5拍结构**，每拍1-2句，DM只需替换世界观细节即可生成高质量开场：

```
【首轮叙事蓝图 — 通用5拍结构】
拍1 — 感官锚定（先听觉/嗅觉/触觉/痛觉，后视觉）
拍2 — 情境建立（当前正在发生什么，而非"日常在做什么"）
拍3 — 异常信号（让玩家产生问题——"为什么/谁/怎么回事"）
拍4 — 角色出现或冲突逼近（最多1-2个角色，各有独立登场理由）
拍5 — 截止点（停在决策前的临界时刻，给出选项）
```

**各开场类型的节拍细节**（在template-skeleton.md中完整展开）：

以"觉醒/初临型"为例：
1. **混沌感知**：先听觉/嗅觉/触觉，后视觉。黑暗中第一个清晰的感知是什么？
2. **身体错位**：尝试动作但身体反应与预期不符。发现"这不是我的手"。
3. **环境锚点**：看清第一个环境细节。此细节必须与后续核心矛盾相关。
4. **第一个异常信号**：暗示有"其他存在"正在靠近。
5. **截止点**：停在"门被推开/脚步声停在背后"之前，给玩家选项。

**叙事质感提升的核心公式：**
```
不说"她在紧张"→ 写"她的指尖绞着裙摆的布料，指节微微发白"
不说"他很帅" → 写"他侧头时下颌线切出的阴影让走廊里对话的声音减半"
不说"气氛尴尬" → 写"空气安静到能听见日光灯管的电流声"
不说"她很生气" → 写"她把茶杯放下的声音比平时大了两个音阶"
```

**冲突设计核心公式（v3.1 融合论文）：**
```
精彩故事 = 情感锚点 × 错位引擎 × 弹性陷阱

情感锚点：故事核心概念中的情感诉求（爱、被崇敬、安全感）
错位引擎：身份/认知/目标的"对不上"持续发电
弹性陷阱：雪球机制（小谎→大谎→引爆）+ 压力锅（封闭环境塞刺激物）+ 安全阀（顶峰释放）
```
