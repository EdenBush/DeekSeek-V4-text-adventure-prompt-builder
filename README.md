## 📖 这是什么？

**Text Adventure Prompt Builder** 是一个专为大型语言模型设计的**元提示词（Meta-Prompt）技能**。它能够根据用户输入的世界观描述，自动生成一份完整、严谨、沉浸感极强的 DM（地下城主/故事导演）提示词，涵盖文风配置、叙事标准、节奏控制、场景写法、情感曲线、角色声音、剧情深度、选择后果、NPC 自主行动、关系变化、自适应格式等 **全部维度**。

无论你想玩一场**仙侠逆袭**、**赛博朋克黑色电影**、**校园恋爱喜剧**，还是**硬核侦探悬疑**——只需要描述你心中的世界，技能会自动推断所有可变参数并生成即开即用的高质量提示词。

## ✨ 核心特性

### 🧠 全维度智能推断
- **四维推断引擎**：自动从用户描述中推断 `故事类型 × 文风配置 × 游戏体验 × 开场模式`
- **六维文风调色板**：叙事节奏 / 描写密度 / 抒情程度 / 幽默模式 / 成人描写 / 对话风格 —— 每个维度独立配置
- **八种故事类型**原生支持，每种有独立的男主原型、叙事调性和系统模块矩阵

### 🧩 模块化系统组装（v3.0）
- **15 个独立系统模块** ，按故事类型智能激活，避免提示词臃肿
- **□ 推荐模块 + ○ 可选模块激活上限**：单次生成不超过 6 个额外模块，保持提示词精简有效

### 🎬 电影级叙事质量
- **5 种场景类型**独立写作参数（战斗 / 对话 / 探索 / 独处 / 过渡）
- **情感曲线管理**：强制冷热交替，防止情绪疲劳
- **高级转场技法**：感官残留桥接 / 主题回声 / 时间压缩蒙太奇
- **渐进式世界观**：开场不糊脸，世界规则通过感官细节渗透

### 🎯 深度互动追
- **选择后果追踪系统**：DM 在 think 中维护选择账本，每 5-8 轮强制后果回调
- **关系微变化系统**：双轴计量（信任/距离），通过肢体语言信号呈现
- **NPC 自主时钟**：每个女主有独立幕后线程，玩家不在场时事情也在发生
- **世界脉动系统**：季节/天气/势力动态独立演进
- **流言/舆论网络**：玩家的公共行为会被 NPC 讨论、扭曲、放大
- **叙事错位引擎**：身份错位 / 认知错位 / 目标错位 —— 三重错位驱动冲突自然产生

## 🎨 支持的故事类型与文风

### 八种故事类型

| 类型 | 男主原型 | 叙事调性 | 喜剧矿脉 |
|------|---------|---------|---------|
| 🏫 **校园恋爱喜剧** | 慢热型/防御型 | 轻松诙谐、内心戏丰富 | 秘密×误会 + 极端角色反差 |
| ⚔️ **仙侠/玄幻逆袭** | 隐忍型/枭雄型 | 冷峻沉稳、暗藏锋芒 | 苟道×意外风头 + 小人物装高人 |
| 🤖 **科幻/赛博朋克** | 务实型/冷酷型 | 冷色调、效率优先 | 系统恶意 + 身份与技术不匹配 |
| 🗡️ **奇幻冒险** | 热血型/成长型 | 明快、大场面 | 文化冲击 + 职业反差 |
| 🔍 **侦探/悬疑** | 理性型/偏执型 | 冷静克制、信息密度高 | 多线程误会 |
| 🧟 **末世/生存** | 果断型/实用型 | 紧促、动作优先 | 日常与超凡的拉扯 |
| 👑 **历史/权谋** | 深沉型/棋手型 | 优雅克制、弦外之音 | 修罗场连锁 + 被迫脑补 |
| 🏙️ **都市/现实** | 普通人型 | 平实自然 | 极致身份错位 + 社死级揭穿 |

## 🔞 NSFW 增强模块

当用户明确要求 R18/NSFW 内容时激活，提供**叙事级**的成人内容支持：

- **第七维文风**：情色描写程度（暗示/留白 → 文学化 → 写实）
- **场景第六型**：亲密/情欲场景的独立写作参数（感官密度、进度节奏、余韵处理）
- **性癖标签系统**：角色级 + 故事级的偏好配置
- **叙事完整性保障**：情欲场景必须推进角色/关系/冲突，不做空洞描写
- **角色一致性**：即使在亲密场景中，角色声音标签和行为模式依然保持
- **情感曲线协调**：情欲后强制安排冷却轮

> ⚠️ 此模块默认关闭，仅当用户**明确要求**时才激活。

## 🚀 快速开始

### 1. 复制技能文件

将 `SKILL.md` 的内容作为系统提示词（System Prompt）发送给 DeepSeek V4。

### 2. 描述你的世界观

最简单的触发方式——直接对 AI 说：
帮我做一个仙侠类的后宫恋爱喜剧RP。
男主是穿越到修仙世界的社畜程序员。
女主有4个：冷淡师姐/腹黑师尊/青梅竹马小师妹/天降魔教圣女。
舞台是青云宗。

### 3. 获得完整 DM 提示词

技能会自动生成一份 10-15KB 的完整 DM 提示词，包含所有系统模块、角色设定、开场引导。将生成的提示词**新建对话**发送给 DeepSeek V4，即可开始游戏。

### 4. 开始冒险

## 📊 质量保障

内置 **30+ 项质量自查清单**：

- ✅ 神经质自查（禁止跨类型套用防御系统模板）
- ✅ 文风一致性自查（节奏/对话/密度与故事类型对齐）
- ✅ 沉浸感自查（开场 3 句内建立物理空间、女主有非视觉感知信号）
- ✅ 开场质量自查（禁止劈柴/扫地/杂役套路、信息配额控制）
- ✅ 模块激活自查（对照矩阵校验、激活上限检查）
- ✅ NSFW 叙事完整性自查（情欲场景是否服务于叙事）
