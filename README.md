## 🆕 v6.1 核心更新 —— 架构修正版

基于 DeepSeek V4 指南原文的技术审计，v6.1 修正了之前版本中与 V4 训练机制不兼容的关键设计：

### 🔧 思维模式标记位置修正（P0）
- **问题**：`【思维模式要求】` 放置在 system prompt 中触发概率显著降低
- **解决**：将标记移至**首条用户消息末尾**，这是 V4 训练时建立的 pattern 匹配位置
- **同时恢复指南原文**：删除了自行追加的第4条英文 “Reasoning Effort”，完全恢复为指南原文的3条规则

### 🚫 移除 Rule Echo
- **问题**：每轮输出末尾追加 `[RC:DM|3rd|SEN|BLK]` 标记对玩家可见，破坏沉浸感
- **解决**：完全删除 Rule Echo 机制，规则保鲜完全依赖 `<think>` 内部的 Rule_Heartbeat + Decay_Watch

### ⚖️ Self_Check 效率优化
- **完整模式阈值调整**：≤5 轮完整模式（原 ≤10），第 6 轮起强制切换标准模式
- **减少早期轮次 think token 消耗**，同时保证关键规则在开局深度内化

### 🎭 新增思考风格选择
- **纯分析模式（默认）**：DM 像导演一样冷静规划，`<think>` 中无括号内心独白
- **角色沉浸模式（可选）**：DM 像演员一样入戏，`<think>` 中允许第一人称内心独白
- 通过 `FIXED SECTION A` 或 `A-ALT` 切换，影响首条用户消息末尾的指令

### 🧹 其他修正
- **版本历史分离**：所有历史版本移至 `CHANGELOG.md`，`SKILL.md` 保留当前概述
- **论文归因修正**：准确区分 V4 特有特性（Interleaved Thinking / 1M 上下文）和通用 prompt 工程实践
- **自然语言密度检查加注释**：明确区分“给 DeepSeek V4 看的生成提示词”和“skill 自身的说明文本”

## 🎬 v5.4–v5.5 累积特性 —— 电影级主角代入 + 防泄漏加固

### 电影级主角代入模式（E-CINEMA · v5.4）
五大专属叙事规则，将 DM 的叙事从“客观记录”提升为“主角视角的完整行为解码”：
1. **行为译解与战略呈现** — 每个玩家指令解码为完整行为链（肢体 + 语境 + 战略）
2. **从结果开始的叙事** — 严禁“你决定/你选择”等代理性开头，始终从动作已发生的世界状态写起
3. **内外双层处理** — 内心情绪通过外部细节暗示，越紧张越松弛
4. **NPC 作为主角之镜** — 所有主角魅力效果只能通过 NPC 反应折射，禁止旁白宣告
5. **主角风格锚定** — 核心气质标签绑定固定身体语言群，高压场景强化反差

### 防泄漏加固 + 注意力智能分配（v5.5.2）
- **防泄漏强制隔离指令**：明确列出所有禁止出现在正文中的内部标记（Self_Check、List_Check、☐、内部模块标签等）
- **Self_Check 优先级标注（🔴🟡🟢）**：核心硬规则始终有最高优先级，V4 在长文本中不会因中间步骤权重稀释而跳过关键禁令

## 🧬 专为 DeepSeek V4 而生 —— 不仅仅是优化，是协同设计

DeepSeek V4 凭借 **Compressed Sparse Attention (CSA)** 与 **Heavily Compressed Attention (HCA)** 将百万 Token 上下文推理成本降至前代的 27%，但其注意力机制的高度结构化压缩也对提示词设计提出了全新挑战。**本技能根本性解决了这一问题。**

| V4 技术特性 | 本技能的针对性设计 | 解决的问题 |
|-------------|-------------------|------------|
| **CSA/HCA 压缩注意力** → 共享前缀缓存权重极高 | **原子化身份护盾** 以 YAML 块置于提示词最开头，转化为共享前缀，最大程度保留在 KV Cache 中 | 500 轮后 DM 仍然记得自己是观察者 |
| **KV Cache 中结构化 Token 权重高于自然语言** | 全部禁令改为结构化 `Forbidden:` 清单，情感曲线、自检模块全部 YAML/表格化 | V4 对结构化规则记忆精准 |
| **Interleaved Thinking** — 推理链可跨轮保留 | 强制 `<think>` 执行顺序，利用跨轮推理维持 DM 状态 | DM 不再“忘记”伏笔、冲突预算、情感强度 |
| **压缩索引器 + 检索标签** | 为每个女主角植入快速检索标签，V4 遇到关键词时自动索引角色卡 | 长上下文里不会串人 |
| **注意力优先级分配** | Self_Check 内新增 🔴🟡🟢 三级标注，核心硬规则始终有最高优先级 | 关键禁令不被稀释 |
| **V4 默认写作本能 vs 禁令张力** | 不仅禁止代理玩家，还提供完整的替代行为系统 | 从根本上消解“犯规冲动” |
| **思维模式标记位置** | `【思维模式要求】` 放置在首条用户消息末尾（V4 训练时的注入位置） | 标记触发概率大幅提升 |

> 📄 *详细 V4 适配原理见 `SKILL.md` 概述部分及 `references/CHANGELOG.md`。*

## 🚀 快速开始 —— 三步开始你的冒险

### 第一步：下载文件

将本仓库的所有核心文件下载到本地：
- `SKILL.md`
- `template-skeleton.md`
- `world-building-guide.md`
- `CHANGELOG.md`
- `references/` 目录下全部文件

### 第二步：拖拽到聊天框

打开 DeepSeek 官网/App，新建一个对话，将 **所有文件同时拖拽** 到聊天输入框中（或全选后复制粘贴）。

### 第三步：说“我要进行RP”

发送以下消息即可启动：

```
我要进行RP
```

然后描述你想要的题材和设定，例如：

```
帮我做一个都市情欲题材的RP游戏。男主是一个意外继承神秘契约俱乐部的年轻人，女主有5个，各有各的秘密和欲望。舞台是一栋老城区的三层小楼。要用电影级代入感。
```

**就这么简单。** 不需要安装任何专门的 Agent 软件，不需要配置 API，不需要学习任何工具。
