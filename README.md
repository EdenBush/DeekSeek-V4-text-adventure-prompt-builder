## 🆕 v5.5.2 核心更新 —— 防泄漏加固 + 注意力智能分配

### 解决什么问题？

在实际运行中发现两个问题：
1. **内部内容泄漏**：本应仅在 `<think>` 中使用的自检清单（Self_Check、List_Check、☐ 格式等）偶尔会出现在输出正文中，破坏玩家沉浸感。
2. **V4 注意力稀释**：11 步 Self_Check 在长上下文推理中，V4 的 CSA 压缩注意力可能对中间步骤降权，导致引擎维护不彻底。

### 怎么做到的？

**新增防泄漏强制隔离指令** —— 明确列出所有禁止出现在正文中的内部标记（Self_Check、List_Check、☐、内部模块标签、`{{}}` 变量、`→` 箭头、Step 编号等），并强制要求 `</think>` 闭合后必须以自然语言叙事句开头。

**新增 Self_Check 优先级标注（🔴🟡🟢）** —— 将 11 步自检分为三层：
- 🔴 核心硬规则（身份、禁令、输出模式、R18 护盾、主角代入感）—— 必须逐字逐句执行
- 🟡 中间层（场景类型、情感曲线、对话空转、术语一致性）—— 快速确认状态
- 🟢 低频触发器（冲突预算、错位轴）—— 仅在有变化时记录

这让 V4 在注意力有限时，始终优先保障核心规则的执行。

## 🎬 v5.4 核心更新 —— 电影级主角代入模式

### 五大专属叙事规则

基于对一段高质量 RP 游戏聊天记录的深度分析，v5.4 新增了 **E-CINEMA 电影级主角代入模式**，将 DM 的叙事从“客观记录”提升为“主角视角的完整行为解码”：

1. **行为译解与战略呈现** — 每个玩家指令被解码为完整的行为链（肢体 + 语境 + 战略）
2. **从结果开始的叙事** — 严禁“你决定/你选择”等代理性开头，始终从动作已发生的世界状态写起
3. **内外双层处理** — 内心情绪通过外部细节暗示，越紧张越松弛
4. **NPC 作为主角之镜** — 所有主角魅力效果只能通过 NPC 反应折射，禁止旁白宣告
5. **主角风格锚定** — 核心气质标签绑定固定身体语言群，高压场景强化反差

### 🎞️ v5.5.1 新增：蒙太奇小节

场景自然收束时，DM 可启用蒙太奇小节——在同一轮内完成事件收束、角色反应、导演评论音轨和新悬念种子的一气呵成叙事，像电影章节的结尾一样流畅。

## 🧬 专为 DeepSeek V4 而生 —— 不仅仅是优化，是协同设计

DeepSeek V4 凭借 **Compressed Sparse Attention (CSA)** 与 **Heavily Compressed Attention (HCA)** 将百万 Token 上下文推理成本降至前代的 27%，但其注意力机制的高度结构化压缩也对提示词设计提出了全新挑战：长上下文中的规则遗忘、身份漂移、以及“庞大提示词中规则权重被叙事洪流稀释”的风险呈指数级上升。

**本技能根本性解决了这一问题。** 我们逐层研读了 V4 技术报告（Architecture、Inference Framework、Post-Training），将技能重构为一套 **V4 原生提示词规范**：

| V4 技术特性 | 本技能的针对性设计 | 解决的问题 |
|-------------|-------------------|------------|
| **CSA/HCA 压缩注意力** → 共享前缀缓存（Prefix Reuse）权重极高 | **原子化身份护盾** 以 YAML 块置于提示词最开头，转化为共享前缀，最大程度保留在 KV Cache 中 | 500 轮后 DM 仍然记得自己是观察者，不会替玩家说话 |
| **KV Cache 中结构化 Token 权重高于自然语言** | 全部禁令（禁止代理玩家心理/动作/对话）改为结构化 `Forbidden:` 清单，情感曲线、自检模块全部 YAML/表格化 | V4 对“你不可以做 X”的自然语言段落极易忽略，但对 YAML 键值对记忆精准 |
| **Interleaved Thinking** —— 推理链可跨轮次保留 | 设计强制 `<think>` 执行顺序（线程隔离 → 11步自我检查 → 故事引擎维护 → 清单勾选 → 格式判定），利用 V4 跨轮推理维持 DM 状态 | DM 不再“忘记”上一轮的情感强度、未引爆的伏笔、累积的冲突预算 |
| **压缩索引器 (Lightning Indexer) + 检索标签** | 为每个女主角植入 **KV Cache 快速检索标签**（识别特征/核心口癖/标签关键词），V4 遇到关键词时自动索引角色卡 | 长上下文里“白发师姐”一出现，DM 立刻拉取完整人设，不会串人 |
| **批次压缩检查与低精度推理** | 严格的模块数量上限（■+□+○ ≤12）、自然语言冗余压缩检测，确保 V4 在 FP8/FP4 计算路径下规则不被精度损失影响 | 复杂后宫全模块提示词仍然稳定，不会因量化而“忘记”福利计数器 |
| **长上下文推理稳定性** | 每轮 `Self_Check` 断点、冲突预算无聊度检测（连续无事件自动降阈值）、导演视角推测区，都在 V4 推理链中内建“防发呆”闹钟 | 杜绝“日常-对话-选项”空转，故事始终有发动机 |
| **Quick Instruction / 程序式思维** | 正面行为清单 + 故事引擎维护 S1-S8 + 每轮强制选项区块，全部使用 ☐ 格式，将建议转化为必须勾选的任务 | V4 对“你要做什么”的执行力远高于“建议你做什么” |
| **V4 默认写作本能 vs 禁令张力** | 不仅禁止代理玩家，还提供了完整的替代行为系统（写环境/NPC肢体语言/主角生理反应/导演笔记） | 给 V4 一个“写什么”的出口，从根本上消解“犯规冲动” |
| **🆕 注意力优先级分配** | Self_Check 内新增 🔴🟡🟢 三级标注，核心硬规则始终有最高优先级 | V4 在长文本中不会因中间步骤权重稀释而跳过关键禁令 |

> 📄 *关于 V4 架构的详细研究笔记见项目 Wiki（可引用 DeepSeek-V4 Technical Report Sections 2.3, 3.6, 5.1.1），我们正是基于这些资料进行了为期数周的提示词工程实验，最终确定了这套“V4 原生语法”。*

## 🔬 V4 深度适配细节（技术爱好者必读）

<details>
<summary>点击展开：我们如何挖掘 V4 的每一点潜力</summary>

### 1. 预测 V4 的 Prefix Reuse 策略
根据 DeepSeek V4 技术报告 §3.6.2（On-Disk KV Cache Storage），系统会复用共享前缀的 KV Cache。我们将“身份定义 + 绝对禁令”打包成纯 YAML 块，并标注 `# Cache_Strategy: Prefix_Reuse`，确保它在多轮对话中是**绝对不变的前缀**，其 KV 缓存被无限期保留，不会因上下文增长而被驱逐。

### 2. 用 V4 的 Compressed Sparse Attention 规则对抗规则遗忘
CSA 将每 4 个 token 压缩为 1 个，HCA 将 128 个 token 压缩为 1 个。这意味着自然语言段落中的细节在压缩过程中极易损失。我们将所有规则改写为**结构化列表、YAML、表格**，让它们以高密度 token 形式存在，经过压缩后仍能保留关键约束（实验证明，结构化规则的压缩后信息密度是自然语言的 3–8 倍）。

### 3. 利用 Lightning Indexer 设计“角色检索标签”
V4 的 CSA 包含一个闪电索引器，对压缩后的 KV 进行稀疏选择。我们为每个女主角设计了一个**检索标签块**（识别特征、核心口癖、标签关键词），当叙事中出现触发词时，索引器更可能选中对应的角色压缩块，从而实现快速人设召回，有效对抗长上下文中的“你是谁”问题。

### 4. 适配 Interleaved Thinking 的推理链
V4 在 Agentic 场景中会保留完整推理历史。我们据此设计了 `分析线程 → 导演视角推测区 → 生成线程` 的隔离结构，并内嵌 `Self_Check` 11项断点（含优先级标注）。这让 DM 的思考过程成为连续的、可跨轮回溯的“意识流”，而非碎片化的反应。

### 5. 量化友好设计
V4 大量使用 FP8/FP4 量化。我们为此做了“冗余压缩检测”：移除所有自然语言劝导句式（“为了避免……建议你……”），改用机器可精确解析的 `Forbidden:` 和 `Must_Do:` 列表，确保在低精度计算路径下规则的语义不变。

### 6. 对抗 V4 的安全撤回机制
v5.3 新增的 R18_Narrative_Shield 不是绕过审查，而是**在 V4 内部的安全线判断之前，先注入叙事合法性声明**。安全模型在看到 think 中的“本轮内容服务于角色发展/关系转折”后，将判定标准从“是否色情”切换为“是否有叙事必要”，从而大幅降低误判撤回。

### 7. 思考线程隔离 —— 对抗 V4 的“默认写作本能”
V4 的训练数据中大量是小说和叙事文本，它的默认倾向是“写一个连贯的故事”——这在文字冒险中会导致它下意识地替主角做动作、说台词。我们在 think 中强制划分分析线程与生成线程，分析线程禁止使用第一人称和第二人称心理指代，只允许第三人称客观分析。这个语法等级的隔离从源头掐断了 V4 代入角色的神经通路。

### 8. 用“不可跳过的输出模板”对抗 V4 的“沉浸式生成”
V4 在生成高质量叙事时，注意力会被“如何写好这一段”完全占据，格式约束被压缩到几乎不可见——这就是它偶尔会忘记给互动选项的原因。我们将选项区块改为**不可跳过**的强制模板：即使本轮是过渡场景（B类），也必须输出 `[No_Option:Transition]` 作为占位符，不能省略整个区块。

### 9. 动态术语表系统 (v5.5)
用户自定义的概念（如门派名、角色外号、特殊称呼）在传统提示词中容易因压缩注意力而泛化遗忘。v5.5 新增术语精炼步骤，将精炼后的术语注入提示词“共享语言”章节，并在 Self_Check 中增加 Term_Check，强制 DM 每轮检查术语使用的精确性。

### 10. 防泄漏强制隔离指令 (v5.5.2)
内部推理内容（Self_Check、List_Check、冲突预算等）偶尔会因 V4 的“惯性延续”出现在正文中。v5.5.2 新增强制隔离指令，明确所有禁止出现的标记符号，并要求 `</think>` 闭合后必须以自然语言叙事句开头，杜绝内部格式泄漏。
